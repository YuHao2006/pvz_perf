# 当前运行时：时间、运动与静态定义

本文维护已经接入本地源码的机制。发布包的使用与兼容性见
[发布说明](releases/v3.1.md)；本地改造不等于已经发布。
当前存档为 DAT64 v4 / schema 0x00010745；运行时只直接读取当前格式。
已发布格式及旧档转换规则见[存档协议](DAT-DAT64-CONVERSION.md)。

## 源定义与资源

持久采样区域统一为 `TextureRegion`：四个归一化浮点 UV 端点，加独立的逻辑绘制宽高。
定义、场景图集、投掷物和头像由离线工具生成；字体、按钮和钱币也使用同一存储。
图集定义不再为了采样保留纹理尺寸数组，`TextureSource` 仅借用 GPU 指针与采样标志。
字体加载与图集重采样、普通 Image 动态局部裁剪仍可临时使用像素参数，
屏幕矩形和业务碰撞框不属于纹理采样区域。浮点偏移改造暂缓。

折行计高与绘制共用一个模板布局实现，测量实例不调用字形绘制。
片尾计高使用已有的纯测量标志，不构造空目标 Graphics；动态宽度和文案仍在运行期排版，
不能仅靠 `constexpr` 把这些输入提前确定。空交集 FillRect、零宽进度条、
编辑选区和没有扩展区域的温室边光在绘制末端跳过。Widget 树遍历保留，
因为 modal、deferred overlay、dirty 清理与恢复裁剪仍有可观察副作用。

Reanim / particle DSL 使用普通十进制参数，直接生成 float，不限制三位小数，
不乘 1000。编译器检查语法、有限值与 float 范围，诊断包含文件、行、字段和原文。
帧号、cel、枚举、数量和图片下标保留整数语义；继承占位值在编译期展开。
实际作者文本是行为数据真值，历史 native 记录只作为独立对照输入。

Reanim 文本规范化检查每个参数重新转为 float32 后保持原位模式；片尾附件速率
保留 29.3125 和 25.59375。粒子显式节点支持省略时间，缺省时间由相邻锚点间的
约分分数确定，例如四节点为 0、1/3、2/3、1，不量化为 .333/.667。
离线记录保留分子/分母；PTC1 运行期记录的 24 字节节点保存离线求值的 double 时间、
float 上下界、曲线与分布 ID，避免每次采样重新除法。

Reanim关键帧、动作区间与外观切换表生成C++静态数组。粒子CPU行为记录在加载期建立共享定义；原始曲线节点保留作者数据，不重新采样成100Hz运动表。
reanim插值、三角函数与顶点变换，以及particle模拟和绘制参数求值均由CPU执行。
粒子数据池持有两个 public `std::array<double, 1024>` 侧表，分别缓存粒子和发射器的归一化年龄比例，不增加实例字段。更新时由当前整数纳秒减出生时间并除以寿命刷新，力场／轨道和绘制复用；不累加浮点年龄、不缓存寿命倒数、不序列化。生成、循环重置、交叉淡出修改寿命和读档后主动刷新；暂停同步平移时间基准，比例保持不变。

GPU接收完成变换的三角形，负责纹理采样、混合与呈现；原GPU常驻reanim／particle路径已撤销，不保留实验回退。
运行期绘制合批和Vulkan提交机制见[Android GPU专项](android-gpu-submission.md)，不得将已撤销的GPU求值实验当作当前路径。

普通资源加载计划为 NRSC4，按具名变量赋值及逆序释放。
ResourceId、ImageSymbolId 和运行时字体 SymbolId 已退役；
历史 879 项资源身份只冻结在离线转换器。代码消费、字体字形页和 alpha 配图共同保护
资源闭包。定义和场景图集不创建逐区域 Image 包装；上传后释放 CPU 解码数据。
具体结构见[资源格式](RESOURCE-V5-FORMAT.md)和[场景 DSL](scene-atlas-dsl.md)。

静态采样区域统一为公共 aggregate `TextureRegion`：
float `mU0/mV0/mU1/mV1` 与 int 逻辑 `mWidth/mHeight`。
图集 DSL／生成器在编译期用已知 atlas 尺寸换算 UV；运行期直接提交采样边界。
`TextureSource` 仅含借用的 GPU 指针和采样 flags。Reanim／particle 定义不再保存
图集尺寸数组，projectile／Zombatar 删除 atlas width/height 成员，
场景模块不再公开 Width/Height；loader 以生成字面量或 PTC1 内的临时尺寸验证 PNG，
不在加载后的粒子定义中常驻另一份采样尺寸。

字体基础字形、缩放字形及排序命令同样保存 UV／逻辑尺寸；
只有加载／resize 的 GPU 像素算子临时使用 Rect。通用按钮四态及 Coin 静态表保存 UV，
复选框无用切片字段已删除。普通 Image 和后端纹理仍保留分配、离屏目标、
clone 和动态像素 crop 所需尺寸。屏幕目标、裁剪、碰撞及业务尺寸未被改为 UV，
浮点绘制偏移任务暂缓。本次只改采样存储，离线装箱仍为整数像素，
PNG、PAK 格式与存档布局不变。

## 主循环与实际步长

目标帧率决定呈现节拍，不是每次逻辑更新必须消耗的固定时间。
用户设置 `targetFps` 最低为 30；读取到低于 30 的数值时立即按 30 使用，
并只改该键回写原设置文件，保留其他配置。Android 启动参数使用相同规则。
`autoDetectFrameRate` 默认 `true`。启用后在窗口创建时查询当前显示模式刷新率，
四舍五入为整数 FPS，再施加最低 30 的限制并回写 `targetFps`；例如 24→30、60→60、
119.88→120、143.98→144。不能查询到有效刷新率时使用 100，不在逐帧路径查询。
Windows 按窗口所在显示器选择；Wayland 未获得 surface enter 通知时按已知输出确定启动值。
缺少该键时补写 `true`；已有显式 `false` 仍保留。当前只在启动时检测，尚未接入运行中的显示模式变更通知。
主循环用steady_clock的整数纳秒采样经过时间；mLastTimeCheck记录采样基准，
mUpdateFTimeAccNs记录尚未进入调度批次的墙钟时间，mPendingUpdatesAccNs记录尚未模拟的有效时间。
呈现与模拟分别保留运行期相位，不进入关卡存档。

单次逻辑更新完整消费本次实际积累的纳秒时间，不截断为10ms，不拆补拍。
目标30Hz时，实际33.345ms就更新33.345ms；超出目标周期的11.667μs只计入
呈现节拍相位，下一次最早在33.321666ms后更新，不会把这段时间模拟两次。
未达到当前应处理时长的墙钟余量继续保留；上一拍超时后允许更短的补偿间隔。
例如目标4ms，5.123456ms后更新一次，下一次最早间隔2.876544ms。
长暂停由显式暂停／恢复分支重建基准；运行中的长卡顿则完整更新实际经过时间，
离散碰撞和力场精度随步长变化，不承诺高速或长卡顿下的原版碰撞精度。
逾期不增加sleep，也不把常规欠时截断为200ms。每批之后绘制，避免高目标帧率造成绘制饥饿。
显式暂停、恢复或清理欠时时重新建立墙钟基准。

每个实际逻辑步同步gUpdateIntervalNs及旧素材速度的换算比例；
应用时钟、视觉时钟和战斗时钟按各自有效更新分支消费同一个实际步长。
不同步长的碰撞、随机事件和离散积分允许差异；reanim相位和根运动继续按共享时钟直接求值。

## 共享时钟与动画

Board 使用裸 `uint64_t mLevelTimeNs`，在效果和对象更新前加上本步有效战斗纳秒，
暂停和战斗停止时不推进，不按原版 32 位 tick 回卷。Visual 时钟在未暂停更新开始时发布，
Battle 时钟由 Board 发布。对象不各自读取系统时钟；存档不保存宿主时钟 epoch。
时钟选择由管理组件负责。Plant、Zombie、Reanimation 和粒子不持有时间域、
不根据场景选择时钟；接口只接收当前纳秒值。附件收到持有者传入的时间。
自由 reanim 的调度归属保存在 ReanimationHolder 的侧表中，由管理组件绑定和重定位基准。

时间由实际使用方显式传入：Board 传关卡时间与本次视觉时间，图鉴传预览视觉时间，
Credits 驱动其主动画，再由父动画把时间传给附件。动画实例统一存放在应用级
`EffectSystem/ReanimationHolder` 的 DataArray 中；存储池不决定图鉴或关卡的播放时间。
Plant、Zombie 和 Reanimation 不再通过 Board、全局应用或 holder 查询当前时钟。
`PrepareTimeAt(nowNs)` 在本次状态／速率修改前推进帧状态，`UpdateAt(nowNs)` 复用同一
处理区间完成轨道更新；查询和变速使用已传入的时间。对象的业务时间、独立视觉时间、
动画求值时间通过明确的时间值参数区分，不向对象传入时间域枚举。

`Board::mPaused` 为真时在推进关卡时钟前返回，不另存冻结标志。
无尽轮末横幅等待期间继续推进关卡时间；切入下一轮 `SCENE_LEVEL_INTRO` 时立即冻结，
包括镜头尚未移动的停留阶段。保留的植物、冷却与战斗粒子不消费过场和选卡期间的时间。
出怪预览从创建、更新到绘制都由 Board 传入 visual 时间。开场草卷等过场粒子由 CutScene
持有并单独传入 visual 时间，不参与 Board 的全局粒子更新；暂停时只对齐基准，不模拟。
泳池闪光 `PARTICLE_POOL_SPARKLY` 是原版初次选卡时仍更新的环境特效，由 Board 单独指定 visual 当前时间；保持全局渲染队列归属，换轮／冰冻时仍遵守原有 `mDontUpdate`，暂停后恢复和读档重绑定只平移出生基准，不补算停顿。粒子不新增时间域字段。1073 冻结分支证据见 [水面闪光核对](../Tests/evidence/pool-sparkle-clock-1073-20261030/manifest.json)。
关卡普通粒子出生于 Board 当前纳秒，EffectSystem 使用 Board 传入的当前纳秒推进，
传送门粒子只走这一次全局更新，GridItem 不再重复更新。粒子更新的步长由持有者的本次
时间与上次已处理时间之差给出，年龄仍为当前时间减出生时间。

本次不改变磁盘格式：原有 reanim 时钟标签由序列化层从 Holder 侧表读写，
记录实际已处理的 `mLastUpdateTimeNs`，不把尚未交给动画的管理者时刻写成动画进度。
粒子存档仍保存相对年龄，加载时以所属 Board 当前时间还原出生值。

每个 `Reanimation` 保存 float 动画速率 `mAnimRate`、当前关键帧 `mCurrentFrame`、关键帧开始时间 `mStartTimeNs`、整数关键帧时长 `mFramePeriodNs` 和完整周期。变速后的帧内年龄为当前所属时钟减关键帧开始时间，绘制与根运动共用，不维护第二套浮点累加相位。

动作或速率改变时建立整数帧时长；普通循环使用N−1个插值区间，full-last-frame使用N个区间并保留末帧。每帧不足一纳秒的时长固定舍弃，更新越过边界的整数余量保留：

```text
ageNs = nowNs - frameStartNs
crossed = ageNs / framePeriodNs
remainderNs = ageNs % framePeriodNs
frame += crossed
frameStartNs = nowNs - remainderNs
```

正向更新用相邻的整数除法／取模直接求跨帧数与余量，再处理周期回绕，不使用逐帧while减法。同一更新时间的绘制／根运动查询复用已归一化帧状态，避免重复除法；倒放和回溯查询保留有符号定位路径，不创建固定100Hz子模拟。变速、正反切换、动作切换和时间域切换在事件处重建基准并保留局部进度。单对象暂停平移时间基准，整局暂停停止共享时钟。周期事件只保留上一处理区间的相位和该区间的回绕量，用于跨阈值触发，不保存自创建以来的累计周期。原版业务使用的 `mLoopCount` 保留，用于动作完成判定；旧 `mPhaseOriginNs` 已删除。

`GetFrameTime` 从共享帧号和帧内年龄直接给出相邻帧及插值比例，避免每次绘制重新整除完整周期。帧内年龄和帧时长均保持整数纳秒；不缓存帧时长倒数，到绘制或位移求值时才临时相除形成插值比例。根运动几何换算系数是派生缓存，初始化／变速／读档时重建，不落盘。固定 `_ground` 下标由编译期表定位。

根运动读取当前关键帧和相邻关键帧，源端点为float，中间值和世界基准用double；普通循环兼容原平均速度的N/(N−1)比例。Reanimation仅在完整周期回绕时累加根运动基础位移；Zombie每次更新以世界坐标绑定偏移加根位移求值，不存已消费周期、乘积缓存或第二套帧时间。坚果保龄球与蜗牛等读取reanim根运动的路径也直接共享帧缓存；Stinky最低速度继续逐源区间处理。

外部改位、传送、动作和身体实例变化使根运动绑定重建；根运动与额外线性位移保持独立锚点。性能边界见[性能原理与基准](perf-fix-ledger.md)，独立候选实验不直接等同落地收益。
线性运动仅变速时，从旧段的 double 原点、速率及整数经过时间重建未舍入末位置，
不将公开 float 输出回灌为新段原点；外部改位或显式失效仍从公开位置重绑。
复用同一状态的非线性模型交接若不符合旧线性样本，则保留原来的 float 重绑方式；
这项检查只在速率变化时执行，不增加常速路径计算，也不将追踪决策宣称为分区无关。

全体对象统一使用 `GameObject` 的一份 float X/Y，公共绘制用 `TranslateF`；
整数碰撞和像素接口在使用边界转换，没有常驻整数坐标副本。
`int(x+offset)` 与 `int(x)+offset` 在跨零时不同，局部复用须保持取整位置。
蜗牛拖影和盾牌回弹绘制在临时平移后直接恢复保存的 Graphics 原值，
不通过浮点减法抵消偏移，避免舍入残留影响后续轨道和物件。
GameObject 的成对绘制入口同样由调用处保存父平移，再将两个 float 值交给
EndDraw 直接恢复；不在对象或 Graphics 中增加状态字段。
按钮及主菜单内部的临时平移也恢复原值；按钮对拍使用小数父平移，
防止整数输入掩盖加减恢复的舍入问题。
僵王后臂的攻击偏移同样保存并恢复共享 reanim 矩阵的两个平移原值，
不以减去偏移还原，避免污染后续身体分组或下一次绘制。

## 发射、弹道与保龄球

植物保存绝对发射 deadline 和已处理窗口游标。周期从旧 deadline 推进，
单步最多追赶 4096 个周期，余下逾期时间留待后续更新。
局部冻结按本步有效战斗时间平移 deadline，不存重复的上次时钟样本；
本步末端出生的植物不会补算出生前时间。
随机间隔直接在原实际端点之间按整数纳秒均匀采样，使用现有 MT 流和拒绝采样消除偏差。
未完成的攻击不反复重启动画，因此 deadline 正确不等于补演所有历史攻击。

弹龄来自关卡时间减创建时间；弹体位置、速度、重力、追踪转向和碰撞按实际纳秒步长模拟。
普通弹体不再维护用于解析运动的段原点、段经过时间或指数采样表。
传送、屋顶、加农炮、附属动画及粒子保留各自业务处理，允许不同步长产生模拟差异。

保龄球横向采样根运动，纵向按目标行到达时刻及 200 像素/秒求值。
单步跨行仍处理到达事件、行桶迁移与反弹，没有私有 100Hz 子循环。
碰撞次数复用与 ZenGarden 倒计时互斥的原槽。
普通坚果保留行中心碰撞窗口；巨型坚果每主步可命中，直接伤害 1,000,000，
继续通过原有伤害和免伤规则。

钱币、阳光和割草机的位移按实际纳秒步长逐次推进，不再用解析位移或指数采样表。
出生、淡出、消失及减速等时间字段保存纳秒起点或结束时刻，由所属共享时钟求年龄或剩余时间。
割草机首次碾压进入250ms最低速恢复段，再次碾压刷新500ms减速周期；速度曲线直接求值，位置逐步模拟。
老虎机按原版4秒内6→2的速度关系逐次推进浮点滚动相位；到期后等待最后一次换卡完成，不重复刷新结束时刻。
100Hz下检查原版滚动和随机序列，其他步长允许离散精度差异。

磁铁物品按反平方加速度逐次更新速度和位置，保留20像素捕获及900ms最长飞行端点。
每物品保存两轴速度，不再保存4097点轨迹表及旧采样参数。
物品从开始吸取起15秒线性缩到0，复用吸取开始时间，不增加独立缩放计时字段。

蜗牛横向继续按reanim的_ground根运动求值，巧克力最低速度按源区间积分；纵向追踪按纳秒步长累加。
重新选目标使用视觉时钟的纳秒结束时刻。睡眠和巧克力的跨退出时长使用用户档中的Unix时间戳，区别于游戏内tick计数。
普通僵尸的reanim根运动、已保留的时间求值高度和冰车爆胎年龄处理不随普通物件回退。
片尾滚动维持独立整数相位；各对象是否暂停由所属时钟及业务分支决定。

## 曲线与粒子

时间曲线入口接受整数纳秒，先求整数时间差，再形成局部比例；绝对epoch不先转float。
距离、坐标、计数和归一化量使用非时间区间入口，不能将其误认为tick。
原始曲线节点、reanim关键帧、UV、轨道掩码及按类型记录的事件阈值不是100Hz运动采样表。
额外指数表、分块幂表、磁铁曲线表和生成器已删除。

粒子和发射器用所属共享时钟减出生时间得到年龄；寿命循环调整出生基准。
局部冻结平移出生基准或结束时刻，不推进模拟或消耗随机数。
位移、速度、自旋及复杂力场按主更新步长离散模拟，已无公式粒子类型、union公式字段或GPU粒子计算路径。

发射器SystemMove直接累加输入；系统定位场按当前与上次采样之差推进中心。
mSystemPositionOriginX/Y沿用旧名，实际保存上次采样值，含义以源码注释为准。
发射数量按当前采样速率和实际步长积分，保留定点余数；不承诺不同步长下随机出生及轨迹完全相同。

图片动画的固定速率相位由出生时间求值，变量速率保留离散积分；寿命和图片动画使用不同出生基准。
CPU生成粒子渲染参数并通过TodTriangleGroup合批，交叉淡出保留深度护栏和原有队列顺序。
