# v3.3.7

DAT64 v4／schema `0x10745` 不变。请成套更新程序和资源。

## 网页

- 主设置区增加默认关闭的“全解锁”：复用现有两个投币／作者本人许可检查。开启后开放已实现的小游戏、解谜、生存关卡及 Limbo 入口，不改写用户解锁进度；关闭后按用户存档判断。原生设置名为 `unlockAllLevels`，游戏内无新增设置控件。
- 检测到 Memory64 支持且包中包含对应运行时，默认选择 wasm64；否则使用 wasm32。忽略旧版自动留下的32位选择，保留新的手动覆盖选项。四个运行时共享资源、设置和存档。
- 高级选项增加“植物动画卡死修复”。仅在游戏未运行时，在隔离工具实例中匹配已验证的玉米加农炮零计时末帧坏档特征。命中后下载原档备份，允许下载修复副本或确认写回本地；没有匹配则不修改。不在游戏更新／普通读档路径中自动修复。
- 音乐状态查询超时不再销毁音频节点，暂用缓存状态避免重复等待；回信恢复后重新同步。真实解码错误仍报告。此项修复确定存在的失声路径，仍需 B站宿主反馈验证。

## 原生及共享 UI

- 恢复花园 GridItem 工具动画在1073双更新下的等效播放速率；不重新执行两次更新。
- 主菜单向日葵周目数提示支持触控点按后保持显示，松手不隐藏，点击其他区域才关闭；不修改鼠标坐标或存档。
- 拉霸文字跟随机器的坐标锚点，禁用的选卡开始按钮不触发悬停文字高亮。
- 恢复关卡选择页石头标题栏投影；取消本轮尝试恢复的灰色内框，未添加文字投影。

“自制关卡”仍为未实现的隐藏占位，不受全解锁开关影响。

## 下载与边界

提供 Windows 10／Vulkan 1.3、Windows 7／OpenGL 3.3、Android 14／Vulkan 1.3、Android 7／Vulkan 1.0，以及四运行时网页版。完美档与无尽基准另附，存档格式不变。

本轮使用桌面构建和自动化回归验证；未新增 Android／Win7 原设备实测。网页音乐恢复仍需 B站宿主反馈，不据桌面测试宣称已解决全部 iPhone 或宿主异常。
