# v4.0.2

- 修复生存模式可变步长在换轮时自动保存了未完成的中间状态，导致重进后无法选卡的问题。自动检查点在最后一次递减前保存；已受影响的存档在读档冷路径恢复为待完成状态，关闭继续对话框后正常换轮。
- 网页版“高级”增加无尽换轮卡档修复，以及存档文件／文本导出、恢复。手机宿主拦截 DAT64 下载时可复制完整文本或分享 TXT。恢复前完整校验，覆盖前保留原档；保存失败会回滚。
- 网页版自定义存档保留进度、布阵和生成关卡；文件导入、导出与已知卡档修复统一移到“高级”。独立 PvzDevTools 的文件工具仍保留。
- 修复和存档备份／恢复不要求投币，处理由独立 wasm32 存档工具完成，不启动游戏、不使用图形或音频。
- DAT64 仍为 v5.1 / schema `0x10747`，没有改变格式。关卡 DAT64 不上传云端，需自行备份。

本版不包含已撤销的普通版图鉴 UI 修补；高清分支的重植版素材调整单独维护。

验证：15 种生存模式的 75 组步长回归、真实玩家卡档恢复、正常状态不误修及最终波快杀恢复；网页独立修复只改变该实档的 1 个字节，保留 84 株植物、阳光及随机数种子；文件／文本备份恢复、校验拒绝和写入失败回滚；WebGL/WebGPU × wasm32/wasm64 四个运行时启动、绘制与正常退出。
