# pvz_perf v2.0

**破坏性更新：存档与 PAK64 均有不兼容变更。请先备份旧存档，并将本版完整解压到新的可写目录。**

本次提供：

- `x64-win10-vulkan-v2.0.zip`：Windows 10/11 x64 + Vulkan，推荐版本。
- `x64-win7-opengl-v2.0.zip`：Windows 7 x64 + OpenGL 3.0，SDR 默认配置。
- `perfect-save-v2.0.zip`：独立生成的完美用户档及 DAT64 v2 无尽基准；
  相同存档也包含在两个游戏包中。

187 份唯一布局的图集编译缓存随 Git 仓库和自动生成的源码归档提供，
位于 `assets/definitions/atlas-cache/`，不需放入游戏运行目录。

## 存档不兼容

游戏只读取和写入 **PVZDAT64 版本 2 的关卡存档**。剩余时间等计时字段采用
64 位纳秒，替代旧版的 10ms tick 等单位。原版 DAT 和 DAT64 v1 关卡档
不能直接在本版游戏中读取，游戏没有旧关卡格式的自动兼容或回退路径。

备份后使用随包的独立转换器升级，例如：

```powershell
data\pvz_dat64_converter.exe --target dat64-v2 "旧目录\game1_58.dat64" "新目录\game1_58.dat64"
```

原版关卡 DAT 也可用 `--target dat64-v2` 转换。不能通过改扩展名完成迁移，
模式编号与文件名规则见[存档转换说明](../DAT-DAT64-CONVERSION.md)。
任意合法纳秒值都会保留，不通过旧 tick 量化；内容 CRC/哈希不参与游戏读档判断，
合法字段可直接编辑。版本、边界、结构和引用关系仍须有效。

上述版本 2 指的是 `game<ID>_<mode>.dat64` 关卡快照。
`users.dat` 用户摘要仍为 DAT，`user<ID>.dat64` 玩家详情仍为 PVZUSR64 版本 13，
三类文件不能混淆。

## PAK64 不兼容与离线图集

**本版 EXE 必须配套本版 `main.pak64`，不能混用 v1.x 的主程序或资源包。**
PAK 容器中的 reanim/particle 定义升级为 v5；旧定义和旧资源闭包不能替代本版。

- 每个 reanim/particle 定义持有 GPU 图集图片，轨道和发射器直接记录矩形区域。
- 最终 compiled 不存储 image symbol ID，也不保存每个区域的图片对象。
- 程序 C++ 使用的图片符号独立维护，不再注入 reanim/particle 编译器。
- 只供定义使用的源图只出现在图集中，运行包不再重复发行独立编号纹理。
- `.pvzbuild` 编译配置统一选择源文件和共享图集组，移除原有聚合 import/export DSL。
- 豌豆家族等定义共享图集；本版生成 193 张物理图集，compiled 图像 symbol ID 引用为零。
- OpenGL/DX9 删除加载期二次装箱，通过公共加载路径直接上传离线图集。
- 上传后释放 PNG 解码像素；图集区域不创建 MemoryImage，滤镜别名复用 GPU 纹理。
- Vulkan bindless 继续按 GPU 纹理描述符工作，图集不需要进入全局图片符号表。

求解采用固定图片朝向和两像素边缘扩展，不为提高利用率增加运行时旋转处理。
当前每个装箱单元的 CP-SAT 预算为 60 秒；超时采用最佳已验证合法排布，并如实保留
`FEASIBLE`/`UNKNOWN`、下界和 gap。200 个装箱单元中 142 个已证明最优，
58 个尚未证明，不能把全部图集称为最优排布。
源码附带经过验证的已完成搜索缓存；中断检查点不会冒充完成搜索或最优证明。

## 运行与性能整理

- 窗口初始比例根据显示器比例选择，保留 800～1400×600 的逻辑画幅范围。
- 主界面左侧采用原生素材补全；保留 QuickPlay 源素材。
- 修正投篮僵尸持球表现对图片身份的依赖，按现有业务阶段与进度判断。
- 绘制复用纹理准备返回的数据，减少重复图片类型查询。
- 合并同一定义的滤镜收集，复用动画帧尺寸，减少粒子源选择的重复判断。
- 删除定义读取数值探针、成功加载及耗时日志、片尾逐帧快慢输出、
  空实现性能探针、无人使用的图片维护/销毁回调和仅供探针使用的宿主回调。
- 保留实际错误诊断、崩溃报告、结构校验和独立测试，不把功能回归结果当成 FPS 提升数据。

## 使用与验证

两个二进制包均附带重新生成的 PerfTest 完美用户档、DAT64 v2 无尽基准、
独立 DAT/DAT64 转换器，以及外部效果和许可；不附带个人设置、个人进度、
生产测试探针、PDB 或运行日志。基准对照前重新恢复随包测试档。

游戏使用 `/MD`，发行包不携带 CRT DLL；运行机器需安装兼容的 Microsoft
Visual C++ x64 运行库，转换器使用 `/MT`。
Vulkan 版本需要支持项目 Vulkan 1.2 和 descriptor indexing/bindless 功能的驱动。
OpenGL 版本需要厂商 OpenGL 3.0 驱动；默认关闭 HDR、自定义缩放和 compute 效果。
随包 effects 在 OpenGL 版本中作为来源和许可保留，不代表支持其计算链。

Win10 Vulkan 与 Win7 OpenGL 目标均完成构建，资源闭包、v5 定义、图集像素、
采样与纹理生命周期、存档计时等回归通过；Win7 目标通过已知不兼容硬导入检查。
OpenGL 验证在当前电脑驱动上完成，尚未在真实 Win7 系统或全部旧显卡上验收。
