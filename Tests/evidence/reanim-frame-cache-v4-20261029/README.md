# v4共享帧缓存：真实API与同范围模型复测

本轮为Windows x64 Vulkan Release /GL /LTCG，MSVC14.51，LP14/0x4000。11x沿用用户控制条件，未独立读回。构建与原生回归结束后串行执行两个独立进程，第二进程反序内核；每内核预热一次、五轮，报告min-of-5。未宣称整局FPS、GPU或手机功耗收益。

最终实现不缓存帧时长倒数：帧内比例仍为double(age)/double(framePeriod)。当前关键帧、帧出生时间在Reanimation内，绘制与根运动共享；Zombie只保存已消费周期与坐标换算状态。sizeof(Zombie)=624、sizeof(Reanimation)=296。Plant568、轨道128、Particle184见[相同结构夹具复测](../production-structure-v4-20261029/README.md)。

## 测量边界

| scope | 计入内容 | 排除内容 |
| --- | --- | --- |
| query_only | 已准备状态下的实际RootMotion／GetFrameTime或旧算术模型查询；共同间接调用、循环、结果编码 | 状态准备、动画推进、模型构建、GPU与矩阵变换 |
| update_and_query | Advance(10ms)完整时钟推进＋相同查询；旧模型计入相同checked时间加法及旧Sample/Consume算术 | 轨道业务Update、附件、碰撞、绘制提交 |
| v4_update_zombie_root | 实际Advance＋Zombie::RootPosition，含周期基础坐标更新 | 完整Zombie::Update与附加运动、碰撞 |

query_only分256批，每批4096次；每批快照准备在计时外，QPC批边界计入汇总。update组每轮100万步，不把更新组数字替代原查询指标。借用当前静态定义，holder为空、显式时钟，无GPU或游戏窗口初始化；LawnApp上下文用于真实GameObject构造，禁读写配置。

frozen_v36_*是根据归档源码重建的正向普通循环算术模型，已解析_ground且不含完整旧API边界、动态定义检查或轨道查找。使用与v4相同的量化周期P=q×区间数，方便逐输出对拍。因此它不是原版EXE、不是旧完整生产函数计时，不能把模型／实际API差值解释成版本回退或优化百分比。

## 正确性与排除项

每种定义在计时前连续推进20000步，逐次对拍实际RootMotion与旧精确公式、实际FrameTime帧号与比例；另核对Zombie基础坐标跨周期累计。Root最大绝对差约9.1e-13px，FrameTime帧号完全相同、float fraction误差为0，Zombie累计最大差约5.46e-12px。冷热拆分前后各内核每轮checksum完全一致，两个进程及两构建的validation.csv逐字节一致。

范围只包括四种正向普通行走循环、10ms步长；倒放、hold、变速、暂停、读档等由主代理真实回归另行验证。本夹具不是完整reanim轨道绘制、三角函数或GPU性能。

早期夹具曾漏建LawnApp上下文，真实Zombie构造触发AV，该运行已作废，未收入任何CSV。修正后在所有Scenario之前构造LawnApp并禁止配置读写；新增VEH令硬件异常仅stderr后退出，防止未来诊断弹框。所有正式运行均exit0、stderr为空。
