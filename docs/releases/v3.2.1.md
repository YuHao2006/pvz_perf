# v3.2.1

本次只发布源码与Git标签，不上传EXE、APK、PAK64或存档附件。

- 修复开场关卡名消失过晚：创建时绑定Visual时间的2.5秒期限，过场中正常消耗，普通暂停时停止，开战不重新起算。
- 修复非循环动画保持末帧时仍增长帧内年龄，导致退出无尽后再次读档报“previous animation phase is outside period”。正放末端和倒放起端保持合法相位，不重复触发事件；读档校验不放宽。
- 水面和闪光统一由Board时间驱动，普通暂停与选卡停止；保留寒冰菇的局部冻结。1073 EXE已确认寒冰菇冻结水面闪光，修正重建代码中的相反赋值。
- 水面使用出生时间与绘制采样时间求相位，在冻结恢复或时钟重新绑定时平移起点，不累加相位年龄。
- 删除Android临时diag.txt输出、音乐槽位诊断及相应接口；保留原生致命错误报告。Windows、Android和程序内版本号统一为3.2.1。

仍使用DAT64 v4（major4/minor0/schema 0x10745），本补丁不改变字段布局；提示仍保存剩余时长，读档按实际所属时钟重绑定。旧v1.x/v2.x程序、PAK64和存档的破坏性边界不变。已经由旧缺陷写出的非法动画快照不会通过宽松读档自动接受。

正式主循环仍为单线程更新。多线程候选只保留为独立测试源码和调查，不接入游戏或GPU提交，也不计入本版性能收益。测试程序和Tests/evidence中的验证输出不参与游戏运行。

相关原理、证据与验证入口见[修复总账](../fix-ledger.md)和[验证说明](../validation.md)。

本次验证：Windows Vulkan Release构建、完整ImageRuntimeTests、帧调度／ReanimClock／v4存档结构检查通过；Android的Common、BassMusicInterface、AndroidMain三个变更文件通过arm64编译。Vulkan绘制测试首次被CTest的60秒限制截断，直接运行同一程序完成全部检查，零验证错误。本次没有重新打包APK或进行手机实机验收。
