# 实际游戏实现与原版EXE查询补测

本报告补齐历史夹具复跑之外的真实函数／真实布局数据，不覆盖1.0历史数字。
MSVC 14.51，LP14/0x4000，11x由用户控制，采集器未独立读回频率。所有正式测量串行；
叶查询按原版—当前—当前—原版运行，随后两个当前结构进程。每个进程每项5轮，下表为各进程min-of-5，单位ns。

原版列直接执行已核验英文1073 EXE的机器码；当前列链接实际Vulkan Release `/GL /LTCG`游戏对象。

当前编译器也允许正常LTO内联，不能将差值全部归因于段表算法或替换旧桩模型的数字。
