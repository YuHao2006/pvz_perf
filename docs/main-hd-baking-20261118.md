## 素材规则

不透明图片继续使用 JPG。外置透明度离线合进自带 alpha 的 PNG，不再运行时查找／组合配套透明蒙版。原有独立字体字形、游戏遮挡／裁剪和特效输入数据不属于配套透明蒙版，继续保留。

33 个唯一 PNG 覆盖上轮已核验的 45 个显式／隐式透明组合配方，相同像素的资源和动画图源复用 PNG。原图和制作输入留在本地归档；图片不加入 Git。详情在 `assets/source-art/main-alpha-retirement-20261118.json`。

## 包体与运行时

最终无损 PAK64 为 **40,266,418 字节**。其中“无损”指包内 PNG／打包压缩策略；原有及烘焙后的 JPG 仍是 JPEG 图片。

可选 `--omit-wasm32-webgpu` 打包模式保留以下三个组合：

- wasm64＋WebGPU（SIMD128）
- wasm64＋WebGL2（SIMD128）
- wasm32＋WebGL2（标量兜底）

32 位模式不会列出 WebGPU，也不会请求缺失的运行时。省下的 wasm32＋WebGPU 在旧四组合 ZIP 中占约 2,637,472 字节。

本地 ZIP **48,220,723 字节**，B站 ZIP **48,220,730 字节**，距 50,000,000 字节上限还余 1,779,270 字节。未解压文件总和约 53.50MB，不把它误报成 ZIP 上传体积。ZIP 的 CRC 和清单文件 SHA-256 均已核验。

## 验证

- 实际 PAK：外置透明蒙版配方 0，自动查找透明蒙版标记 0。
- Vulkan／OpenGL 原生解码：45 个透明组合配方与原生 RGBA 基准完全一致。
- 两后端商店图像：日夜／开关门四种状态，关门最大通道误差 0，开门最大通道误差 1。
- 图鉴水生植物、800／1400 宽度裁剪和焦散时钟；普通／高底座对话框尺寸回归。
- 浏览器中三个运行时均实际进入游戏；32 位页面不提供 WebGPU。32 位用例还移除 Object.hasOwn，检查旧浏览器兼容路径。
- OpenGL 在 Windows 11 上使用 Win7 目标构建验证，不代表 Windows 7 实机验收。
