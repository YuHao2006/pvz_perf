# 高清／普通版存档交叉验证与网页内存测量

日期：2026-11-17。使用本地隔离副本，没有改写用户存档。

两边均使用 DAT64 v5.1，schema 0x10747；用户资料为 USER64 v13。高清版使用当前 2× PAK 123,729,310 字节，普通版使用当前原分辨率 PAK 39,587,202 字节。

已用各分支真实生产代码、各自资源包和原生 Vulkan 渲染器执行：

1. 普通版原始无尽档 → 高清读入／写出／同版重读。
2. 高清写出的文件 → 普通版读入／写出／重读。
3. 普通版再次写出的文件 → 高清读入／写出／重读。
4. 两边分别创建全部 reanim 类型，生成包含 347 个活 reanimation 的测试档；各自写后重读通过。
5. 高清全类型档 → 普通版读取并再次保存／重读，通过。
6. 普通版全类型档 → 高清读取并再次保存／重读，通过。

测试还检查精确时间、动画外观、粒子继续更新、根运动及投射物轨迹的同版写后重读不变。原始输入 SHA256 始终未变。日志位于两个本地工作区的 out/verification/hd-main-save-compat-20261117/。

测试入口增加 PVZ_SAVE_ALL_REANIMS=1，仅用于回归测试，不改变游戏运行时或存档格式。此结果覆盖 DAT64 原生序列化兼容性，不能当成所有关卡人工游玩通过，也未代替正式 Toy 宿主的云存储权限验证。

高清网页源码已同步直接 IndexedDB、共享空间标识及时间戳同步模块，保留高清版原有图形初始化差异；已有旧网页包不会自动更新。云端仅用户资料和阵型库，完整关卡云档仍未启用。

网页内存实测见 [web-memory.json](web-memory.json) 与 [存档文档](../../../docs/web-save-storage.md)。
