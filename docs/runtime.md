# 当前运行时：时间、运动与静态定义

本文维护已经接入本地源码的机制。发布包的使用与兼容性见
[发布说明](releases/v2.0.md)；本地改造不等于已经发布。
当前开发中的存档布局尚待统一命名为 v4，不承诺中间布局互相兼容。
已发布格式及旧档转换规则见[存档协议](DAT-DAT64-CONVERSION.md)。

## 源定义与资源

持久采样区域统一为 `TextureRegion`：四个归一化浮点 UV 端点，加独立的逻辑绘制宽高。
定义、场景图集、投掷物和头像由离线工具生成；字体、按钮和钱币也使用同一存储。
图集定义不再为了采样保留纹理尺寸数组，`TextureSource` 仅借用 GPU 指针与采样标志。
字体加载与图集重采样、普通 Image 动态局部裁剪仍可临时使用像素参数，
屏幕矩形和业务碰撞框不属于纹理采样区域。浮点偏移改造暂缓。

折行计高与绘制共用一个模板布局实现，测量实例不调用字形绘制。
片尾计高使用已有的纯测量标志，不构造空目标 Graphics；动态宽度和文案仍在运行期排版，
不能仅靠 `constexpr` 把这些输入提前确定。空交集 FillRect、零宽进度条、
编辑选区和没有扩展区域的温室边光在绘制末端跳过。Widget 树遍历保留，
因为 modal、deferred overlay、dirty 清理与恢复裁剪仍有可观察副作用。

Reanim / particle DSL 使用普通十进制参数，直接生成 float，不限制三位小数，
不乘 1000。编译器检查语法、有限值与 float 范围，诊断包含文件、行、字段和原文。
帧号、cel、枚举、数量和图片下标保留整数语义；继承占位值在编译期展开。
实际作者文本是行为数据真值，历史 native 记录只作为独立对照输入。

Reanim 文本规范化检查每个参数重新转为 float32 后保持原位模式；片尾附件速率
保留 29.3125 和 25.59375。粒子显式节点支持省略时间，缺省时间由相邻锚点间的
约分分数确定，例如四节点为 0、1/3、2/3、1，不量化为 .333/.667。
离线记录保留分子/分母；PTC1 运行期记录的 24 字节节点保存离线求值的 double 时间、
float 上下界、曲线与分布 ID，避免每次采样重新除法。

Reanim 关键帧、动作区间与外观切换表继续生成 C++ 静态数组。
粒子每个根生成一份 PTC1 CPU 行为记录及一份 PGP1 GPU 绘制表，共各 106 份；
程序只保留根槽位及路径表，不再生成 `ParticleData*.cpp` 曲线、力场或 UV 数组。
PTC1 在加载时建立共享 emitter、track、field 和 variant UV 行，释放时销毁；
PGP1 的绘制曲线和几何在离线展开，主线程上传 GPU 后丢弃上传缓冲。
实例仍共享根行为，以 variant 选择外观。公共曲线表直接索引，
离线编译器及运行期加载器均检查记录边界和编号。

Reanim DSL 支持 `cpu:`、`gpu:`、`both:` 区域，未声明时默认 `both`；
`cpu Track {...}`、`gpu Track {...}`、`both Track {...}` 仅覆盖单条定义，
不会改变后续轨道的区域默认值，具名轨道也支持此前缀。
现有素材保持全部 `both`。逻辑轨道槽位不重排；GPU-only 的 CPU 关键帧指针
为空，CPU-only 的 GPU 描述符保留槽位并标记无关键帧。
CPU 业务仍直接读取生成的 C++ 数组；GPU 的 GRU1 上传文件单独生成。

`PVZ_EXPERIMENTAL_GPU_REANIM` 控制 reanim 的实验绘制策略，
不控制粒子的 GPU 绘制：粒子没有 `cpu:`／`gpu:`／`both:` 区域或 CPU 绘制回退。
粒子要求后端提供常驻定义和原始状态提交接口；Vulkan／OpenGL／DX12 构建始终启用
所需后端能力，Metal 已接入源码但仍待 macOS 验证，D3D9 当前不提供该能力。
以下实验开关、稀疏选择与 CPU 回退说明仅适用于 reanim。
开启实验时，装载条嫩芽与僵尸头的图集及 GPU 定义在 `LawnApp::Init` 中准备，
早于 `Start` 显示原生窗口；其余 GPU 定义留到全量装载屏障之后。
公共上传入口在首次实际上传前结束已有绘制帧，保留装载屏／缓存的待提交绘制；
重复调用且没有新定义时不额外结束帧。后端仍禁止在开放帧内上传定义或扩容常驻缓冲区。
共享实例输入为 64 字节；OpenGL 常规 GS／独立 VS 附加图集信息后为 80 字节，
其余后端及 OpenGL compute 试验／旧 GS 回退附加裁剪信息后为 96 字节；
每条图片轨道另交 32 字节差异输入。GPU 每轨一次计算插值、三角函数、
矩阵及裁剪，直接输出绘制顶点，不将变换结果读回 CPU。
共享实例延迟到首条符合条件的图片轨道才创建；同组 GPU-only 轨道也共享强制实例，
纯文字分组和稀疏帧的可选 CPU 回退不创建实例包。
共享实例持有分组裁剪，逐轨标志选择默认裁剪；旧逐轨 GPU 入口使用的独立矩形
只在实际进入该回退路径时准备，不在共享提交成功的每条轨道上重复构造。
Vulkan／OpenGL／DX12 共享实例在创建时验证定义和纹理，
成功销毁资源时使匹配的实例引用失效；逐轨提交直接检查实例状态，
不重复执行存活集合查询，Vulkan／DX12 也不再重复读取 owner。
Begin 接收仍存活的原始句柄，调用方在销毁后清空自己的句柄。
已经排队的 GPU 数据及纹理
仍按原有退休规则保留，旧 token 在销毁、Flush 和资源重建后不会重新生效。
resident 开启时，合成图片的 raw 清理也使用这个销毁入口。
Vulkan／OpenGL 的普通三角形与轨道 marker 保持原顺序；较长的连续普通三角形段使用原顶点管线，
避免少数动画使整帧普通图片承担 geometry shader 成本。
Vulkan 普通段在提交时记录已知的管线族与 blend 槽位，Flush 直接索引普通或常驻管线表，
不再根据原生管线句柄逐项反查；四个管线族覆盖主画面、离屏图片及各自的字体 coverage。
管线表在排队期间保持有效，呈现管线不进入这条普通段队列。
常驻索引缓冲在恢复对应绘制状态时绑定，不随 scissor／blend 引起的每段冲刷重复绑定；
水波绘制及目标切换会使状态失效，随后同时恢复常驻索引缓冲和 uint32 索引格式。
状态变化判定也直接复用先前比较结果，不在冲刷前后重复比较管线和 scissor。
OpenGL 非 compute 提交统一记录 VBO 顶点区间，普通 Submit 不生成索引；
Flush 在已有分段遍历中一次生成 resident 段所需的 EBO，长普通段直接 DrawArrays，
不再先生成索引再移动／丢弃。顶点与轨道编号、绘制顺序和批次数不变；
仍按展开后的虚拟索引总量检查范围。独立 compute 路径保留原 EBO 区间与展开索引。
OpenGL 每次 Flush 从未知状态开始，在批次循环内复用未改变的纹理绑定、
scissor、blend 和各 program 的 coverage uniform；不跨 Flush 缓存这些状态，
也不增加 renderer 的持久成员。
OpenGL 常规 GS 路径直接输出四角，使用批次已有的 scissor 执行有效整数裁剪，
不再上传实例裁剪矩形或执行 shader 多边形裁剪；独立 compute 试验保留原 GS 回退作为对照。
Vulkan／DX12 使用 precise 多项式，OpenGL 使用自身 native sin/cos 路径。
Vulkan／OpenGL／DX12 的常驻定义缓冲区支持扩容及释放区间复用；
扩容在 GPU 内复制已有数据，释放区间等待对应提交完成后才能重新分配，
存活定义的偏移保持不变。DX12 使用 32 位字节寻址，单个缓冲区上限为 4GiB。
Metal 使用相同多项式，针对该 shader 关闭 fast-math 与浮点乘加收缩，
不使用 MSL 不支持的 HLSL `precise` 关键字。Metal 每批连续兼容轨道先 compute，
再直接使用 private GPU 顶点缓冲绘制；当前上限每批 4096 条，较大序列分批保持顺序。
Metal 的实现和 Apple 专用夹具已加入源码，尚未在 macOS 编译或执行。
Metal 当前实验分配器仍是固定容量追加分配，尚未具备上述扩容和区间复用机制。
开启实验时，首帧仍走 CPU。后续依据上一完整批次的真实图片轨道候选数及普通
三角形总数选择路径，内部目标切换不重置统计；当前门槛为至少 256 条候选，
且普通三角形不超过候选数的 32 倍。`gpu:` 轨道强制 GPU，
不受稀疏策略降级影响；不支持该 GPU 路径的硬件会在加载这类定义时明确报错。
文本、运行时 blend、额外高亮/overlay 和变换栈继续走现有路径。
Vulkan／OpenGL 密集及均匀混合的独立实验已通过各自门槛；冷热切换成本和
DX12 性能继续单独验收，
不能将 CPU 回退的稀疏帧伪称为一次 GPU 性能收益。
测量时钟未锁频，具体数字只保留在系统临时目录，不作为性能报告数据。

普通资源加载计划为 NRSC4，按具名变量赋值及逆序释放。
ResourceId、ImageSymbolId 和运行时字体 SymbolId 已退役；
历史 879 项资源身份只冻结在离线转换器。代码消费、字体字形页和 alpha 配图共同保护
资源闭包。定义和场景图集不创建逐区域 Image 包装；上传后释放 CPU 解码数据。
具体结构见[资源格式](RESOURCE-V5-FORMAT.md)和[场景 DSL](scene-atlas-dsl.md)。

静态采样区域统一为公共 aggregate `TextureRegion`：
float `mU0/mV0/mU1/mV1` 与 int 逻辑 `mWidth/mHeight`。
图集 DSL／生成器在编译期用已知 atlas 尺寸换算 UV；运行期直接提交采样边界。
`TextureSource` 仅含借用的 GPU 指针和采样 flags。Reanim／particle 定义不再保存
图集尺寸数组，projectile／Zombatar 删除 atlas width/height 成员，
场景模块不再公开 Width/Height；loader 以生成字面量或 PTC1 内的临时尺寸验证 PNG，
不在加载后的粒子定义中常驻另一份采样尺寸。

字体基础字形、缩放字形及排序命令同样保存 UV／逻辑尺寸；
只有加载／resize 的 GPU 像素算子临时使用 Rect。通用按钮四态及 Coin 静态表保存 UV，
复选框无用切片字段已删除。普通 Image 和后端纹理仍保留分配、离屏目标、
clone 和动态像素 crop 所需尺寸。屏幕目标、裁剪、碰撞及业务尺寸未被改为 UV，
浮点绘制偏移任务暂缓。本次只改采样存储，离线装箱仍为整数像素，
PNG、PAK 格式与存档布局不变。

## 共享时钟与动画

Board 使用裸 `uint64_t mLevelTimeNs`，在效果和对象更新前加上本步有效战斗纳秒，
暂停和战斗停止时不推进，不按原版 32 位 tick 回卷。Visual 时钟在未暂停更新开始时发布，
Battle 时钟由 Board 发布。对象不各自读取系统时钟；存档不保存宿主时钟 epoch。
附件继承属主时间域，自由视觉效果可继续使用 Visual。

每个动画保存恒速段起点、相位原点、周期、循环基准与 float 速率。
动作或实际速率改变时建立一次整数纳秒周期：

```text
periodNs = floor(frameCount * 1_000_000_000 / abs(rate))
phaseNs, cycles = EuclideanDivRem(origin + direction * (now - start), periodNs)
```

固定周期最多舍弃不足一纳秒，只在建立周期时发生，不逐步累计浮点相位。
公共采样仅返回周期数和周期内纳秒，不再生成随即又除回的每源帧 10^9 刻度。
普通循环 N−1 插值与 full-last-frame 的 N 区间、末帧保持分别处理。
变速和正反切换保留局部进度；主动 seek、动作切换和时间域切换明确重建基准。
整局暂停停止共享时钟，单对象暂停保留本地周期和相位。
宽乘除使用原生 128 位路径及精确软件后备，保留除零与商范围检查。

根运动从周期累计位移及当前帧内插值直接求值，不将上一次舍入的位置作为下步输入。
源端点为 float，中间值和世界基准使用 double；普通循环兼容原平均速度的 N/(N−1) 比例。
Stinky 最低速度逐源区间积分，不能用两份累计位移取最大值替代。
外部改位、传送、变速和身体实例变化使绑定重建；根运动与额外线性位移使用独立锚点。
线性运动仅变速时，从旧段的 double 原点、速率及整数经过时间重建未舍入末位置，
不将公开 float 输出回灌为新段原点；外部改位或显式失效仍从公开位置重绑。
复用同一状态的非线性模型交接若不符合旧线性样本，则保留原来的 float 重绑方式；
这项检查只在速率变化时执行，不增加常速路径计算，也不将追踪决策宣称为分区无关。

全体对象统一使用 `GameObject` 的一份 float X/Y，公共绘制用 `TranslateF`；
整数碰撞和像素接口在使用边界转换，没有常驻整数坐标副本。
`int(x+offset)` 与 `int(x)+offset` 在跨零时不同，局部复用须保持取整位置。
蜗牛拖影和盾牌回弹绘制在临时平移后直接恢复保存的 Graphics 原值，
不通过浮点减法抵消偏移，避免舍入残留影响后续轨道和物件。
GameObject 的成对绘制入口同样由调用处保存父平移，再将两个 float 值交给
EndDraw 直接恢复；不在对象或 Graphics 中增加状态字段。
按钮及主菜单内部的临时平移也恢复原值；按钮对拍使用小数父平移，
防止整数输入掩盖加减恢复的舍入问题。
僵王后臂的攻击偏移同样保存并恢复共享 reanim 矩阵的两个平移原值，
不以减去偏移还原，避免污染后续身体分组或下一次绘制。

## 发射、弹道与保龄球

植物保存绝对发射 deadline 和已处理窗口游标。周期从旧 deadline 推进，
单步最多追赶 4096 个周期，余下逾期时间留待后续更新。
局部冻结按本步有效战斗时间平移 deadline，不存重复的上次时钟样本；
本步末端出生的植物不会补算出生前时间。
随机间隔直接在原实际端点之间按整数纳秒均匀采样，使用现有 MT 流和拒绝采样消除偏差。
未完成的攻击不反复重启动画，因此 deadline 正确不等于补演所有历史攻击。

弹龄来自关卡时间减创建时间，运动段另存绝对起点与 XYZ、角度及阴影起点。
普通直线、星星、三发偏移、抛射和旋转从基准与整数经过时间求值；
抛射沿用原先更新速度再更新位置的理想离散递推延拓，不要求逐 10ms 迭代。
追踪弹按主步转向和碰撞，允许不同步长产生不同轨迹。
传送移动运动基准，保留出生时间；加农炮保留下降段所需目标信息。
无消费者的普通弹体选帧与点击退避字段已删除，附属动画和粒子保留。

保龄球横向采样根运动，纵向按目标行到达时刻及 200 像素/秒求值。
单步跨行仍处理到达事件、行桶迁移与反弹，没有私有 100Hz 子循环。
碰撞次数复用与 ZenGarden 倒计时互斥的原槽。
普通坚果保留行中心碰撞窗口；巨型坚果每主步可命中，直接伤害 1,000,000，
继续通过原有伤害和免伤规则。

钱币/阳光拾取、磁铁、老虎机的已落地公式及有意改变的原版行为，
见[运动时间求值](research/coin-magnet-time-motion.md)。
钱币下落从飞行段原点、初速度和整数经过时间直接求值；重力沿用原
`y(n)=y0+n*v0+a*n*(n-1)/2` 递推的连续延拓，礼物减速使用几何级数。
墙碰撞和落地按原 10ms 边界定位事件，外部改位或改速重建运动段；
飞行时复用 `mCollectX/Y` 为段原点、`mDisappearCounter` 为段经过时间，
拾取和落地后分别恢复这些字段的原用途，初速度另存。
植物产出阳光的缩放使用独立原点和整数经过时间，只有 `UpdateFall`
实际运行时才推进，菜单冻结期间不会因 `mCoinAge` 继续增长而跳变；
达到上限时固定终点时间，外部修改缩放则重建段。
割草机以整数经过时间采样运动，咀嚼减速按原有限速度序列积分，
入水／出水高度直接由固定端点和整数经过时间求值；
Zombiquarium 脑子下落也由运动基准和整数经过时间求值。
蹦极、气球下降、进出泳池、高地、落地及爬梯高度也采用独立运动段；
小鬼抛物线使用先加重力再移动的递推闭式，原点相对行 Y 保存，
屋顶行高直接参与求值，不累加逐步的行高差。
高重力气球的落地与额外下降合并推进一次，避免同一步两次重建基准。
雪橇车将速度和位置作为同一条运动轨迹求值，复用现有横向运动段；
曲线使用源 float 端点推导的系数，指数项使用编译期采样表。
跨越 700／400 边界时定位原 10ms 事件，并保留最后一次曲线计算的尾速，
爆胎减速沿用先减速再移动的递推闭式。
片尾滚动使用独立整数循环相位，仅在原滚动分支推进，暂停、调试同步和跳帧控制流保留；
严格越过底部才回卷，因此循环长度包含额外一个原始 10ms 步。
部分 UI 反馈仍有逐步积分；
蜗牛 Y 追踪按用户决定保留累加，不声称全工程消除了浮点反馈。

## 曲线与粒子

时间曲线用 `TodAnimateCurveNs(int64 ns)`，先计算整数差再形成局部 double 比例，
绝对 epoch 不先转 float。距离、坐标、计数和归一化量使用普通 double 区间入口。
旧浮点时间与无额外行为的转发接口已删除。中间多项式使用 double，最终浮点输出仍为 float，
整数输出只在末端按既有规则舍入；正反区间、端点钳制和回摆语义保留，零时长立即完成。
迁移验收覆盖 170 个业务调用点，其中 114 个时间入口、56 个非时间／归一化入口；
这是静态源码数量，不是每帧调用量。

粒子每次有效主更新按当前时间求值或做一次场积分，没有固定 10ms 子步或隐藏出生整步。
寿命以整数纳秒保存，CPU 更新需要的上一年龄从当前年龄及有效 delta 临时推导，
归一化寿命临时由 age/duration 计算，
不扣除一个 tick。循环保留超出时长，随机初始年龄直接在纳秒范围采样。
源时长单位仍为固定 10ms，速度、位移、加速度与旋转按实际 delta 比例处理；
摩擦使用 `pow(max(0,1-f), deltaRatio)`，离散粒子场中的定位和 shake 使用采样差。

发射器的系统定位场由外部输入、双精度基准偏移和当前寿命相位的曲线值直接求和，
只在最终公开坐标处转为 float，不累加前后采样差；多场先求和，再加位置基准。
外部移动仍只采样一次 held 输入，寿命循环直接重新采样曲线。
删除 `mSystemLastSampleAgeNs`，新增两轴 double 基准及 uint32 绑定标志；
原生存档尾由 40 字节变为 52 字节。历史记录没有该基准，解析定义后在推进时间之前，
由已保存中心及当前曲线反求一次基准，不重放存档中已生效的偏移。

无粒子场、或只有单节点恒定加速度场的位移使用运动段，以 double 起点和整数累计时间求值，
末端才转为公开的 float 坐标，不再把逐步舍入的坐标作为下步输入。
寿命循环和图帧动画不重置运动时间。
位移段保存两轴 double 起点、int64 段时间、起始速度及恒定加速度。
公开速度也由起始速度与经过时间直接求出；与旧时刻样本比较以发现外部变速，
外部改位入口同步调整位移基准；变速保留旧段未舍入端点，
单轴编辑只替换对应轴。`mLinearElapsedNs == -1` 表示出生／力场交接后尚未绑定；
已经绑定的零时刻仍可保留精确起点。开发存档尾保存这些字段，历史转换以未绑定状态开始。
恒定加速度使用 `q = elapsedNs / 10_000_000`，
`v = v0 + a*q`、`p = p0 + v0*q + a*q*(q+1)/2`。
其中 a 是每原版 10ms 的速度增量；`q+1` 来自原版先改速度再改位置的递推，
保持整数 q 的原版检查点，同时允许任意纳秒采样，不执行 100Hz 子步。
单节点 low/high 的随机系数由出生时的插值固定，多加速度场先求和。
恒速／恒加速度运动、且自旋速度至多一个节点时，自旋也使用同一个整数段时间。
单节点的 low/high 随机范围由出生插值固定；绝对角度曲线按当前寿命相位求值，
不把逐步角度差累加进旋转。位移或自旋重设段起点时，同时保留未修改通道的 double 端点。
自旋段保存不含绝对角曲线的 double 起点、double 速率及 uint32 启用标志；
标志区分自旋按段求值或离散采样，位移的时钟不因后者失效。
公开坐标及角度的外部编辑通过本步起点重建时的临时样本识别。
前一步年龄、位置、自旋及 emitter tick／alpha／scale／颜色等绘制缓存已从运行期对象删除；
开发存档仍保留原 wire 布局，退役的扩展年龄／位置／自旋及保留缓存槽写零，
读取时丢弃；冻结的旧格式 float 相位仅在编码时从当前年龄投影，
不恢复为运行期缓存，也不按缩小后的 C++ 对象直接 memcpy。
运动段和所需的时间、随机插值及控制状态继续保存。
稳定段只采样当前绝对角；上一时刻角度曲线仅在绑定起点、公开角度编辑或离散积分时求值，
不在每次更新中重复计算已被基准表示的旧角度。
多节点自旋速度、变化加速度及其他力场组合仍按原主步采样／积分，
切回常量段时从当前状态重新绑定。粒子模拟、出生、力场及存档仍由 CPU 维护。
绘制仅提交整数纳秒年龄与时长、位置、自旋、随机插值、控制覆盖值和交叉淡出链等原始状态；
GPU 执行绘制曲线、颜色／亮度、scale／stretch、图帧、裁剪及顶点变换。
绘制入口不在 CPU 预求这些结果，也不读回 GPU 顶点；UI 与关卡使用同一路径。
交叉淡出链的原始状态按原顺序提交，图集纹理仍由共享加载注册表拥有。
附着的 held 位置输入变化时平移线性起点；输入没变时跳过逐粒子加零向量的循环。
这些结构及绘制迁移尚无新的正式性能结论。

粒子运动明确分成公式模型和离散模型。恒速、恒加速度、已验证的独立
Away，以及编译期生成幂函数采样表的摩擦组合属于公式模型：保存运动起点、
出生参数和整数纳秒时间，由 GPU 直接求值；恒速和恒加速度直接使用乘加公式。
Circle 与其他力场组合、Shake 反馈、GroundConstraint、变化力场以及依赖字段
顺序的反馈路径属于离散模型：按主步更新位置和速度，绘制直接使用这个离散
位置，不在相邻主步之间重建或频繁切换运动曲线。离散模型不引入隐藏的 100Hz
子步，只有公式模型使用纳秒时间直接取样。

GPU 提交不上传每粒子的运动类型字段。CPU 先检查交叉淡出链，再分别调用公式
粒子和离散粒子的提交入口；一个提交批次只包含一种状态布局。离散状态为 192
字节，公式状态在相同公共前缀后追加段起点时间、起点、速度、加速度和自旋段参数。
绘制描述只携带整批状态步长与模型选择，shader 按批次读取公式参数或直接读取
主步提交的位置；没有逐粒子的 kind 分支。公式模型的时间差由 GPU 从整数纳秒
时钟求出，离散模型不在相邻主步之间插值位移；交叉淡出链混合的是已经提交的
视觉状态。交叉淡出开始时，若公式链需要转成离散链，转换在 CPU 侧使用同一套
公式一次完成，不从 GPU 读回位置。

常量发射率按二进制 float 与累计有效纳秒计算精确积分差，保存 10^12 单位余数；
发射时钟不随 emitter 寿命循环归零。有限系统和淡出只积累有效发射时间。
变量率按主步末端采样并积分，不承诺分区一致。
出生与 OnDuration 在主步末端处理，新目标从 age 0 开始；
系统在更新前快照原有粒子 ID，避免同一步新生目标再次消费整步。

每系统保存独立随机流，创建时从全局流取一个种子，后续步骤和出生只消费本地流。
shake 由出生种子和整数采样年龄决定，不依赖地址或全局 rand。
常量图帧速率由整数累计动画时间直接求相位，保留旧档初相位锚点；
变量率保存离散积分。动画时间独立于随机初始寿命和寿命循环。
零时长与暂停不改变状态、不消费 RNG，也不采样 held `SystemMove` 输入。

同初始状态、同速率及同一离散事件时间轴下，动画相位和根运动可检查更新分区一致性。
力场、碰撞、shake、变化率及附件输入采样仍依赖主步。
既有布尔事件消费者可能合并大步中的多次事件，不保证全游戏任意步长状态一致，
也不保证跨平台 float 位模式相同。验证入口与实际覆盖见[验证说明](validation.md)。
