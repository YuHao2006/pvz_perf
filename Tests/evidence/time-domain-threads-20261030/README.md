# Domain worker experiment, 2026-10-30

See docs/research/time-domain-threading.md for scope, limitations, ownership audit and median table. Baseline v3.2; production remains single-threaded. Final CSVs contain 144 rows total, three rounds per population/mode/affinity/scope. Every run exited zero with an empty error log. Each includes an untimed 24-frame bitwise matrix oracle per population, plus timed per-frame checksum checks. Snapshot capture and actual draw submission are excluded. Delay mode drains its last job in the reported mean and blocks before reusing an outstanding job; this is not a nonblocking/drop-frame queue. Source is Tests/performance/time_domain_thread_experiment.cpp; runner tools/test-time-domain-threads.ps1 reconstructs the matched compile/link commands from the current build graph.
