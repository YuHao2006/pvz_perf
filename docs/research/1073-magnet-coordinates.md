## 坐标查询

`Zombie::GetTrackPosition` 为 `0x545050`：
通过轨道名称找到下标，调用 `Reanimation::GetTrackMatrix`（`0x477240`），
然后将矩阵平移量加上僵尸的 float 位置（`+0x2c/+0x30`）。
没有 reanim 实例则返回僵尸 float 位置。不是用整数碰撞框坐标查询道具位置。

```asm
005450c0: call 0x477240
005450c5: fld  dword ptr [esi + 0x2c]
005450c8: fadd dword ptr [esp + 0x14]
...
005450d3: fld  dword ptr [esi + 0x30]
005450d6: fadd dword ptr [esp + 0x1c]
```

## 各物件的原版分支

吸取函数位于 `0x464fc0..0x4656a3`。W/H 以下均指对应原图的尺寸，
半尺寸的计算是整数除二，不能直接当作缩放后图片的半尺寸。

| 物件 | 原版取起点的顺序与公式 |
|---|---|
| 铁桶 | 清除头盔状态，查询 `anim_bucket`；隐藏轨道，然后减铁桶原图 W/2、H/2 |
| 橄榄球头盔 | 清除头盔状态，查询并隐藏头盔轨道；随后**覆盖**为僵尸 float 位置加 `(37,-60)` |
| 铁门 | 脱盾，非啃食时切回行走，再查询 `anim_screendoor`；减铁门原图 W/2、H/2 |
| 手持梯子 | 脱盾；直接用僵尸 float 位置加 `(31,20)`，再减摆放梯子图片 W/2、H/2；不查询手持梯子的轨道 |
| 跳跳杆 | 先 `PogoBreak(16)`，再查询 `Zombie_pogo_stick`；加 `(40-W/2,84-H/2)`，尺寸取 `IMAGE_REANIM_ZOMBIE_POGO_STICKDAMAGE1` |
| 玩偶匣 | 停音、选速、改状态并隐藏箱子/把手，再查询 `Zombie_jackbox_box`；减箱子原图 W/2、H/2 |
| 矿镐 | 先 `DiggerLoseAxe`，再查询 `Zombie_digger_pickaxe`；减矿镐原图 W/2、H/2 |

两个明确的反编译差异：

1. 头盔分支 `0x46524b..0x465261` 从 `[edi+0x2c]` 和 `[edi+0x30]`
   重新取僵尸位置再写回物件，而不是在轨道查询结果上 `+=37/-=60`。
2. 跳跳分支 `0x46547f`、`0x4654a6` 使用全局指针 `0x726f78` 的 W/H。
   其赋值点 `0x48573e` 对应字符串 `IMAGE_REANIM_ZOMBIE_POGO_STICKDAMAGE1`，
   不是反编译源码中的梯子图片。摆放梯子图片是另一个全局指针 `0x726b94`。

原版绘制函数 `0x468eb0` 重新加接收植物的高度偏移；铁器以 0.8 倍缩放绘制，
跳跳杆使用 `IMAGE_ZOMBIEPOGO` 的独立帧。它并未把僵尸轨道的完整旋转/缩放矩阵
传给飞行物件。因此原版存在人工偏移和换姿态，不能宣称它对所有物件都严格保持原姿态。

## 起点连续性修复约定（2026-10-24验证）

为满足吸取起点连续的要求，统一在脱盾、破坏道具和切换动画**之前**读取源轨道中心。
随后根据实际选择的磁铁物件矩形及其绘制缩放，换算为左上角坐标，
并抵消 `DrawMagnetItems` 将重新加上的植物高度偏移。
摆放的梯子直接匹配 `GridItem::DrawLadder` 的 `(gridX+25,gridY-4)`。
生成与绘制共用同一张静态物件到图集条目表，不新增对象字段或每帧查找。

这有意改善原版的近似起点，不声称完全复刻原版固定偏移。
保持的是转移时图片矩形中心的位置；磁铁物件仍使用自己的独立图片与 0.8 倍绘制，
没有新增旋转或缩放过渡，图片轮廓不保证逐像素保持原姿态。

实际游戏代码回归测试覆盖七类源轨道、0.5/1.0 倍与镜像缩放姿态，
独立取源轨道矩阵，与转移后物件的绘制中心比较；另在当时曲线路径检查零时间采样保持起点。当前轨迹已改为逐步模拟，这项历史检查不作为当前运动接口说明；见[运行时](../runtime.md)。
地面梯子另通过实际 `UpdateMagnetShroom` 选择与删除，核对转移前后左上角。
Vulkan 与 Win7 OpenGL 的完整资源、缺失、损坏、尺寸错误四种 fixture 场景均通过；
两个 Release 可执行文件均已重建。未修改存档布局或用户存档。
