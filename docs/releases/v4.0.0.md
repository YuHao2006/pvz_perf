# v4.0.0

本版是破坏性更新。程序、资源、着色器和 DFU 必须整套替换，不能只替换可执行文件。

## 时间与存档

- 当前关卡格式为 DAT64 v5.1，schema `0x10747`。将倒计时改为预期时间，减少对象保存的“上一次更新时间”；离散粒子由持有者传入当前时间和本次更新区间，保留逐步模拟。
- reanim 保留整数纳秒相位与帧缓存，运行时不缓存浮点帧时长倒数。
- 独立 DataFixerUpper（DFU）自动将正式 DAT64 v4 升级到当前格式，同时修复已确认的旧射手攻击动画卡死。Windows 使用 data/pvz_dfu.dll，Android 使用随包的 libpvz_dfu.so，网页使用独立 wasm32 工具，均不依赖启动游戏来转换。
- 正确的 v5.1 存档直接读取，不检查动画修复；转换失败不会覆盖原档。未发布的 v3 / v5.0 中间格式不支持。
- 原版 DAT 可通过 data/pvz_dat64_converter.exe 手动转换，该程序与自动升级共用 DFU 模块。

## 网页与发行包

四个原生平台：x64-win10-vulkan1.3、x64-win7-openGL3.3、arm64-android14-vulkan1.3、arm64-android7-vulkan1.0。

网页包含 wasm32 / wasm64 与 WebGPU / WebGL 2 四种游戏运行时；支持 Memory64 时自动选择 64 位，存档工具始终是独立 wasm32。继续使用已有正式版的浏览器存档目录，进入游戏前自动升级历史 v4 关卡档。高级设置中的手动“植物动画卡死修复”入口已移除。

附带完美用户档与原版起点转换的无尽基准，当前为 v5.1；完美档包含坚果包扎术。个人存档和开发期日志不随包发布。

本版未重新宣称整局性能提升。最近一轮同条件整局观测与前轮接近，详见性能总账与原始测量记录。

B站包在资料回写与正常 Quit 后自动备份用户资料／进度和阵型库，上传中显示红字提示。设置页常驻提醒：关卡 DAT64 不上传云端，只保存在当前浏览器，须自行导出备份。
