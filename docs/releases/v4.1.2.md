# v4.1.2 高清版

Windows 10 x64 和 Android 14 arm64 均提供 Vulkan 1.3 的 1200p、2400p 完整包。每个包都自带对应的资源和默认配置。另附完美存档和带无尽基准的完美存档，存档格式为 DAT64 v5.1。

窗口和交换链跟随实际显示尺寸。1200p 档以 2800×1200 为内部渲染上限，2400p 档以 5600×2400 为上限。超过任一维度时，场景按比例渲染，最后以双线性采样放大。Windows 用户可以自由拉大窗口，退出后保留尺寸。显示设置集中在 `settings.json`，安卓菜单可切换横板 UI，重启生效。

高清网页包使用 wasm64、SIMD128 和 WebGPU，已启用 B 站平台检测。首次进入时若共享存档为空，请在普通版进入游戏并正常退出。普通版的高清入口将在高清 Toy 上线后更新。

Windows 超阈值放大已通过手测，Edge 已验证跨阈值切换。UHD 630 上反馈的 Vulkan 低帧原因仍待实机确认。
