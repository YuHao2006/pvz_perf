# v4.0.6 普通版改动

- 小游戏、解谜、生存三个选关页共用重植版背景，窗口变宽时只伸缩中段。图鉴首页、植物页、僵尸页分别组合纸面、页框、装饰和标题牌。石牌和木牌的投影按 1073 原图恢复。以上贴图均从高清母图离线缩到普通版 600p 规格。
- Windows 下，游戏按逻辑更新用 `GetCursorPos` 读取鼠标悬停位置。只剩鼠标移动时，消息泵提前返回，混合输入每轮最多处理 32 条，让游戏在持续移动鼠标时也能推进更新与绘制。点击沿用按键消息自带的坐标。
- Windows 无尽基准图新增两条标有数值的虚线，分别显示全场平均 FPS 和平均每绘制帧 CPU 时间。两项均按前台有效战斗区间的总量计算。
- 透明图片使用自带 alpha 的 PNG，普通图片加载时默认关闭配套蒙版探测。旧位图字体仍可读取独立字形页。B 站打包报告显示实际文件大小和 ZIP 大小，取消 50 MB 对照标记。

## 下载

GitHub 提供 Win10 Vulkan、Win7 OpenGL、Android 14 Vulkan、Android 7 Vulkan 和网页端的无资源包，以及 Windows 调试符号和完美存档。Windows 将同版本普通版 `main.pak64` 放在 EXE 旁运行。网盘四个完整包可直接解压或安装。

- `windows-x64-pdb-v4.0.6.zip` 分目录收录两个 Windows 后端的 PDB，按崩溃时使用的 EXE 选择。
- `perfect-save-v4.0.6.zip` 提供完美档；`perfect-save-and-endless-v4.0.6.zip` 另外包含无尽基准局面和对应原版格式。请先备份自己的存档。
- 普通版 600p 的 `main.pak64` 共 39,842,857 字节，SHA-256 为 `8c9ce098ff43dbadcd5659699cdcb100d3567ffab11624e00a3b82d61c1d31f3`。

图鉴标题牌与投影使用同一张 600p 素材。三个挑战页的石牌保留左上、右下碎块，奖杯随右边框移动。桌面候选版已通过作者手测。
