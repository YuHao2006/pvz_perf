# 主界面高清母版

这里的五张 `*-4x.png` 为原版逻辑尺寸的四倍，供后续 4 倍分辨率使用。当前 1200p 分支只使用它们缩小一半得到的 2 倍运行图；母版与原始 AI 输出不进入运行资源包。

`raw-ai/` 保存本轮六张 AI 原始输出，未裁剪、未缩小。实际生成尺寸见 `manifest.json`，并非每张 AI 原始输出都正好是原图四倍。四倍母版直接从这些原始输出配准、重采样、拼接产生，没有从二倍运行贴图反向放大。

`manifest.json` 保留完整提示词、原始尺寸、SHA-256、成品尺寸和来源；`source-layout.json` 保留原图分块坐标；`registration.json` 为离线几何校正记录。背景右侧未重新生成的区域沿用此前 AI 版本并校正到原图位置。
