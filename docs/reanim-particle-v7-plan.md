# Reanim / Particle v7：千分制源数据与步长无关的运动方案

状态：设计方案，尚未修改编译器、游戏定义、存档或生成数据。

## 目标与一致性边界

- DSL 中的小数最多三位；隐含分母统一为 1000，编译器直接解析为整数。
- 同一动作、初始进度、速度及同一整数时间轴上的状态切换，在相同累计时间处得到相同的 reanim 进度与根运动位置，不受外层更新拆分影响。
- 三位限制属于作者数据精度，不限制内部计时精度，也不把每次插值结果强制截断到三位。
- 仅改变数值表示不能让碰撞、力场或逐更新随机采样自动与步长无关；这些消费者另行采用共同事件时间或固定内部步长。
- v7 是 reanim / particle 定义与编译器版本，不等于游戏版本或存档版本。存档变化单独升级，不覆盖原格式。

## 已核实的源数据

当前配置选择 177 个 reanim DSL 文件、2694 条轨道。排除继承占位值后：

| 字段 | 显式数值数 | 可还原原 float32 位模式的小数位 |
|---|---:|---:|
| X/Y | 231154 | 1 |
| skew X/Y | 190397 | 1 |
| scale X/Y | 124634 | 3 |
| alpha | 922 | 2 |
| fps | 146 | 最多 2 |

23 条 `_ground` 的 1159 个 X、54 个 Y 都能由一位小数还原。
这里证明的是将短十进制重新转换为 float32 能复原原位模式，不是定点数与原浮点数作为数学实数完全相等。

Particle 当前配置选择 112 个 DSL 文件。剔除字符串、注释后统计到 4903 个数字字面量，最多三位小数，没有超限样本。
此项为源文本统计，不代表编译器补全的节点时间或运行时随机值也恰好只有三位小数。

## DSL 与静态定义

1. 小数字段采用普通十进制文本，例如 `x: -9.8; scale-x: 0.792;`。
2. 词法层限制小数点后最多三位，包括尾零。`0.1234`、`1.0000` 报错，给出文件、行、字段和原文；不静默舍入。首版不接受指数、十六进制、NaN 或 Inf。
3. 直接拆解符号、整数和小数文本，右补零到三位，生成 `int32_t`。禁止先经过 strtof 再乘 1000。
4. 帧号、枚举、图片下标、数量等整数语义字段仍保存整数，不把它们乘 1000。
5. 旧 `-10000` 继承占位符在编译期解析并展开，不变成运行时的特殊定点值。
6. 现有 reanim 长尾文本一次性规范化。迁移工具必须验证“规范化文本转回 float32”与旧位模式相同；严格 v7 编译器本身不接收旧长尾。
7. 源变换定义生成整数静态数据；绘制时生成临时浮点变换。GPU 指针、图集矩形、变体和所有权方案保持现有设计。
8. 原始粒子曲线节点值与显式作者时间保存千分制整数；省略时间按节点序号或编译期约分比例补全，不先舍入为千分制时间。

不增加通用小数包装类、访问器或指向另一层包装的指针。public 整数成员、静态数组、const 引用足够。

## Reanim 的权威播放进度

源 fps 和选定的运行时动画速率统一表示为 `rateMilli`，单位是千分之一动画帧/秒。
外层更新提供 `deltaNs`，单位为纳秒。

定义内部播放时钟：

```
clock 增量 = deltaNs * rateMilli
一动画帧   = 1_000_000_000_000 个 clock 单位
一动作周期 = frameCount * 1_000_000_000_000 个 clock 单位
```

这是单位相乘得到的精确整数比例，不是把 DSL 扩展成十二位小数。
常量速率下，所有分步的 `deltaNs * rateMilli` 之和严格相同；没有逐步丢弃的余数。

实例保存周期内整数 clock、带方向的累计周期数，以及事件检测所必需的上次播放位置。由整数除法/余数一次求出跨过的周期数，支持单步跨多个周期。
当前和上次位置都是权威整数进度，不再持久保存 float mAnimTime/mLastFrameTime。
最终成员布局在实现时核对既有 mLoopCount 消费者，避免重复保存可推导状态。

倒放采用明确的欧几里得商余规则，保证周期内 clock 非负。
暂停就是 rateMilli 为零，保留当前进度；变速只改变以后消耗时间的速率。
动作切换和主动跳转显式建立新的进度及运动基准，不从取整后坐标反推。

乘法、周期长度和插值乘除编译期/运行期都有边界检查；公共 MulDiv 按需要使用宽中间结果，不能依赖有符号溢出。常规更新保持原生整数运算。

速率在同一整数时间发生改变时，跨越该时刻的大步必须分段消费，不能把新旧任一速率套到整步。

## 帧定位与根运动

编译器为每个动作生成动作范围、循环模式需要的采样区间信息、根运动累计位移和速度换算常量。
区分普通模式的 N-1 插值区间与 full-last-frame 模式的 N 区间及末帧保持；禁止统一后偷偷改变原循环语义。

用整数 clock 计算当前帧及帧内分数。绘制可将该分数临时转换为 float；逻辑根运动使用整数分子/分母求值。

```
运动位置 = 固定运动基准
         + 完整周期位移
         + 当前周期累计位移
         - 建立基准时的周期内位移
```

累计位移由两个源关键帧插值，周期位移按完整周期数计算。每步都直接从基准求位置，不再累加 speed * delta。
周期末尾的不足一个像素或不足一个千分单位不得丢掉。
整数碰撞坐标只在最终输出时按现有向零截断规则产生，不反馈到下一步；负数不能用 floor 替代向零截断。
外力位移、传送、换行等离散事件显式更新运动基准。

当前速度实现存在 N 与 N-1 的换算差别。首版以旧连续积分模型为兼容目标：
普通循环的根运动补上 N/(N-1) 的精确比例；full-last-frame 按原末帧保持处理。
这避免把当前速度采样误差修复与平均速度重新平衡混在一起。
这个兼容比例由编译器生成，不逐次用浮点计算。

`mVelX` 到动画速率的计算改用整数比例，最终明确舍入到千分之一帧/秒。它会与旧任意精度 float 速率产生一次性差别，必须单独报告；这不是随更新次数累计的误差。
基础随机速度统一在指定整数范围中抽样，种子/取样顺序固定，不能每次按目标 FPS 重新随机。
冰减速等比例变更必须明确处理奇数千分速率的半单位；首版按统一舍入规则量化实际速率，不声称所有减速组合都能被千分速率无损表示。

僵尸、保龄球、蜗牛、僵王火球以及附属动画同步中的 `_ground` 使用点一起迁移。
绘制用到的浮点矩阵、三角函数结果不回写权威运动进度。

## 动画事件和直接写相位的调用点

- 事件时间编译成动作内的精确阈值，按明确的半开区间判断跨越；单步跨多个周期逐个产生事件。
- 原 ShouldTriggerTimedEvent 的边界方向在实现前固定下来，不能复制目前漏掉多周期的判断。
- 使用目标帧或千分制归一化位置描述主动 seek，不继续直接写 float 相位。
- 多头植物等同步动画复制整数播放位置；动作范围不同时进行明确比例换算。
- 轨迹快照、片尾字幕、主菜单云层和存档中的相位字段也必须迁移，不能只改僵尸。

## Particle v7

Particle 当前仍有：

- 参数节点的 float 时间、上下界及缓动/分布求值；
- 由纳秒 age/duration 派生的 float 归一化寿命；
- float 位置、速度、旋转、图像动画进度；
- float 发射数量累加器；
- 与更新次数有关的力场积分和随机震动。

v7 的 DSL 数字和源定义采用与 reanim 相同的千分制规则。
age/duration 继续以整数纳秒为权威，曲线求值使用 age/duration 比例，不将归一化寿命作为可变累加状态。
随机分布在粒子生成或指定事件时抽样，保存种子/抽样结果，不能因外层更新次数不同而额外抽样。

纯时间曲线可直接按时间采样。发射数量不能仅把浮点累加器改整数：变速发射曲线需要累计积分或固定内部步长，确定出生的整数时间和出生顺序。

含摩擦、吸引、地面碰撞、震动等状态相关场，首版建议保持原 100 Hz 作为统一内部模拟步长，外层按纳秒累计消费完整内部步。
这提供的是固定内部时间点、相同输入/随机种子下的一致结果；不会声称只换成定点数就实现任意步长解析积分或跨平台位级相同。
外层绘制插值前后两次状态可得到平滑画面，但常规做法有一个内部步长的显示延迟，必须作为明确选择，不能隐藏。
如果不接受该延迟，需另选外推或部分场解析求值；那是另一项取舍。

因此粒子 v7 分为源数据/时间与随机机制迁移，以及状态相关力场的固定内部步长迁移。二者均列入范围，不能只升级版本号便宣称全部粒子与步长无关。

## 存档与验证

新存档保存权威整数播放位置、速率、根运动基准以及必要的 particle 状态和随机状态；派生帧号和临时绘制浮点不重复保存。
存档版本与定义 v7 分开命名，原版/v1/v2/v3.2 的已承诺转换路径保留，新格式加入明确转换路径。
旧 float 相位按固定规则量化为新 clock；旧浮点运算历史不可恢复，不宣称旧存档能还原“从新机制开始运行”的历史。

验收条件：

1. 两类 DSL 三位精度、越界、非法字面量、行号报错和规范化校验。
2. 同一累计纳秒，30/60/100/144/200/240/1000 Hz 和随机拆分的整数播放位置完全相同。
3. 根运动最终整数坐标逐样本完全相同；与旧连续积分模型单独比较速率量化差。
4. 正反向、暂停、非零起始相位、多周期大步、full-last-frame、动作切换、同步及存档续播。
5. 相同事件时间轴下，事件次数/顺序、粒子出生数量/顺序一致；力场在共同内部时间点状态一致。
6. 性能分别测进度推进、轨道采样、根运动和密集粒子；不将整数算法默认当作更快。
7. Vulkan / Win7 OpenGL 的绘制回归、加载上传即弃、存档转换及读取回归。

实施顺序：严格数值解析与源迁移 → 静态定义 → 整数播放时钟/事件 → 根运动调用点 → Particle 时间/发射/力场 → 存档转换 → 双后端验证。
在未获得实施指令前，本文件只作为可审阅方案，不触发上述代码或格式改动。
