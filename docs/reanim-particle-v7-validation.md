# Reanim / Particle v7 验证记录

历史基线提交记录为 `a116e68`，v7 实现及后续修复尚未提交，也未推送。
本文当前布局以 schema `0x10738` 为准；下方明确标注的历史验证记录属于此前布局，不能代替当前时间戳版本的最终集成验证。

## 数据与时间

- DSL 参数恢复普通小数，生成 float 源定义，不限制三位精度；源 FPS、attacher rate 和运行时动画速率均使用正常 `float` 值。
- 动画使用共享整数纳秒时间戳：`ReanimationHolder` 保存 `mVisualTimeNs` 与 `mBattleTimeNs`，动画通过公开的 `mTimeDomain` 选择时间域，并保存恒速段起点 `mStartTimeNs`。采样由当前共享时间与起点之差、相位原点、周期和循环基准推导，不再为每个动画逐帧累计 elapsed；变速和时间域切换保留当前局部进度。
- Board 的 `mMainCounter` 为单调纳秒时钟，超过原 `2^32` ticks 范围后不会按旧 unsigned tick 周期回卷。Board 在对象和效果采样前发布 Battle 时间；暂停和停止动作时间的路径不推进它。Visual 时间独立发布。
- 植物周期发射使用绝对关卡时间 `mNextLaunchTimeNs`，另保存 `mLaunchClockSampleNs` 和 `mLaunchWindowStartNs`，用于冻结剩余时间与记录事件处理进度。周期从旧 deadline 推进；睡眠、离开有效攻击状态等原本冻结倒计时的路径会平移 deadline 与游标，保留剩余纳秒。
- 发射周期随机值在旧实际端点之间按整数纳秒闭区间均匀采样，仅在初始化或周期事件时抽签。采样使用游戏原有全局 MT 随机流，组合 31 位输出并通过拒绝采样消除取模偏差。射手周期范围为 `[rate−14 ticks, rate]`，生产周期为 `[rate−150 ticks, rate]`，其中一个 tick 为 10ms。
- 保龄球碰撞次数与 ZenGarden 生产倒计时互斥复用原 `mZenProductionCountdown` 槽；保龄球每次碰撞增加一个 legacy count，没有新增独立的 `mBowlingImpactCount` 成员。
- 根运动按周期基准加当前相位插值计算。Plant / Zombie 只有一份正常 float 像素坐标。
- 根运动直接读取 float 关键帧，以 double 中间值求位移并返回浮点结果；源端点和根运动结果不进行千分量化。
- 粒子采用固定 10ms 内部步长，保存余数和本地随机状态。绘制最近完成的状态，可能滞后不足 10ms。
- 存档为 **v3.3**：主版本 3，小版本 3，当前 schema `0x10739`。游戏只直接读写当前布局；转换器支持原版、v1、v2、v3.2、v3.3，并将早期千分坐标布局 `0x10736`、浮点相对时间布局 `0x10737` 和角色时间戳布局 `0x10738` 作为输入升级，统一输出 `0x10739`。
- 原速相位诊断和轨迹快照使用每源帧 `10^9` 单位；粒子内部的 `10^12` 周期单位是独立的无量纲表示。

## 当前存档精确状态布局

以下偏移均相对于 canonical 记录之后的精确状态 tail，不是 native 对象成员偏移。Plant tail 为 **56 字节**，Reanimation tail 为 **68 字节**，Projectile tail 为 **36 字节**。

| 记录 | Tail 偏移 | 内容 |

| Plant | 0–23 | float 坐标、double 根基准和根绑定信息 |
| Plant | 24 | 8 字节保龄球目标行到达时间 |
| Plant | 32、40、48 | `mNextLaunchTimeNs`、`mLaunchClockSampleNs`、`mLaunchWindowStartNs`，各 8 字节 |
| Projectile | 0、8 | 创建时间、当前运动段起点时间，各 8 字节 |
| Projectile | 16、20、24 | 运动段起点 XYZ，各 4 字节 float |
| Projectile | 28、32 | 运动段起始角度、阴影 Y，各 4 字节 float |
| Reanimation | 0 | 4 字节时间域，Visual=0、Battle=1 |
| Reanimation | 4、12、20、28 | 起始时间、相位原点、周期、循环基准，各 8 字节 |
| Reanimation | 36、44、52 | 上次事件相位、上次循环数、1 字节历史有效标志 |
| Reanimation | 56、60 | 4 字节 playback generation、8 字节保存时的时间域时钟快照 |

Plant tail 在偏移 48 的 8 字节游标之后结束，没有额外次数字段或末尾 8 字节保留区。保龄球计数和 ZenGarden 倒计时继续使用原 canonical/ns 辅助槽。

旧存档迁移先按各自冻结的 tail 长度读取：10736 的 Zombie/Plant/GridItem/Reanimation 为 40/32/232/60 字节，10737 为 80/32/240/60 字节，10738 为 80/56/240/68 字节，三者均没有 Projectile tail，再转换为当前布局。植物 deadline 使用完整旧 ns 剩余值加保存的 Board 时间，不经临时 legacy tick 投影舍入。旧动画使用 `start = Boardnow − oldElapsed`，保留相位、周期、循环和事件历史；历史格式生成的相对草稿在取得 Board 时间后绑定。旧保龄球由当前 Y、目标行和地形重建到达时间。旧弹射物保留完整纳秒弹龄，并以保存的 Board 时间和当前坐标、速度作为新运动段起点，避免恢复时跳跃。

保存动画时，tail 偏移 60 写入所选共享时间域的当前时钟快照。加载后使用 `RebaseTime` 绑定当前时间域时钟，保留局部进度；Visual 时间在不同 session 中的绝对起点可以变化。

## 弹射物坐标回归

用户实测发现寒冰豌豆弹体留在零坐标、玉米粒绘制正常但不造成碰撞。
原因是清理 Zombie 旧像素坐标缓存时，误删了 Projectile 初始化的 `mX/mY` 赋值和每次运动的 `mX` 同步。
Projectile 仍继承像素坐标的 GameObject，碰撞框等消费者仍需要这些字段。
已恢复三处同步。后续角色坐标回退到 float 时保留这些弹射物同步，不改变弹射物存档布局。

## 一致性与性能边界

相位和根运动的一致性以相同初始状态、速率和状态切换时间轴为前提。
粒子一致性以相同内部采样时刻的输入和随机种子为前提，不承诺跨平台 float 位模式相同。
既有布尔动画事件消费者可能合并大步内的多次事件，其他碰撞和输入采样也未整体迁移，因此不声称全游戏任意步进完全一致。

植物发射 deadline 处理每次更新最多消费 4096 个到期周期，剩余逾期 deadline 留待后续更新，不丢弃积压时间。`mShootingCounter` 等攻击动作时序仍保留原机制；大步长遇到尚未完成的攻击时会消费周期机会而不反复重启动画。因此 deadline 一致性不等于任意大步长下能补演所有历史攻击动作。

本轮属于数据表示、时间机制和存档结构改造，尚无完整运行时性能测量，不能将整数化直接写成性能提升。
