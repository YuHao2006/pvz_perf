# v4.1.1 高清版

Windows 10 x64 Vulkan 1.3 包内置 2× 资源。需要更高清的贴图时，退出游戏，用单独下载的 4× 文件替换程序目录下的 `main.pak64`。

Android 14／Armv9-A／Vulkan 1.3 提供 2× 和 4× 两个 APK。两包共用应用标识和签名，可覆盖安装。4× 包需要更大的纹理容量和显存。高清版尚未实现按场景动态卸载贴图。

- Windows 窗口宽高可独立调整，客户区范围为 800×600 至 5600×2400，并保存窗口尺寸。修正了逻辑宽度取整造成的右侧单像素黑线。
- Windows 设置菜单提供 HDR 开关，在 `settings.json` 中保存，重启生效。显示器处于 SDR 时以 SDR 启动。
- Android 画布和 Vulkan 交换链跟随实际窗口尺寸。实机确认游戏缓冲从 1333×600 提升到 2480×1116，2× 包已手测通过。Android 使用 SDR。
- 附完美存档及带无尽基准的存档包。存档继续使用 DAT64 v5.1，与普通版互通。
- UHD 630 上反馈的 Vulkan 异常低帧仍属已知问题。

高清网页包另行准备，仅面向支持 Memory64、SIMD128 和 WebGPU 的浏览器。平台上线另行安排。
