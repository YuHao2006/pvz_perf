# pvz_perf v3.0

**破坏性更新：关卡存档和 PAK64 不兼容旧发行版。请备份旧数据，将整包解压到新的可写目录，不要混用 EXE、shaders、资源包。**

本次发行 `x64-win10-vulkan-v3.0.zip`（Windows 10/11 x64 Vulkan，推荐）和 `x64-win7-opengl-v3.0.zip`（Windows 7 x64/OpenGL 3.0，SDR）。完美用户档和基准无尽档同时作为独立附件提供，两个游戏包也包含它们。OpenGL 包包含普通贴图硬件采样专项优化，性能收益尚未实测；功能验证使用当前 Windows/NVIDIA 驱动，不代表真实 Win7 或所有旧显卡认证。

## 存档边界

游戏只读取和写入 DAT64 v4（schema 0x10745）。转换器支持原版1073 DAT、DAT64 v1、v2、v4；不支持未发行的 v3/v3.1/v3.2/v3.3/v3.4 等中间格式。玩家详情仍为 PVZUSR64 v13，用户摘要格式独立。

```powershell
data\pvz_dat64_converter.exe --target dat64-v4 "旧目录\game1_58.dat64" "新目录\game1_58.dat64"
```

原版泳池无尽使用 game1_13.dat，转换后本项目使用 game1_58.dat64。完美档为生成的 PerfTest/ID1：双周目、奖杯、成就、十卡槽、商店永久升级、智慧树1000；花园与自定义头像为空。基准档每次测试都应重新解压恢复起点，不要用推进后的关卡作为比较基线。

## 当前实现

- reanim/particle 与场景、投掷物图集在编译期生成；CPU 计算动画和粒子，GPU 负责绘制，粒子公式路径已删除。
- reanim 使用纳秒关键帧时钟，缓存当前帧号与帧开始时间，根运动按帧内相位插值；僵尸与保龄球共享该机制，不记录累计周期来重复推导位置。
- 粒子与发射器年龄由当前时间减出生时间求值，归一化比例放入派生侧表，不保存冗余运行缓存。
- 改造主循环步进及事件期限；修复植物攻击漏轮、撑杆/投掷小鬼运动绑定、保龄球、种子包冷却裁剪等回归。
- Vulkan/DX12 调整贴图采样与提交路径，减少 GPU 每像素工作和重复状态操作；透明边缘预处理保留加载期缩放能力。
- OpenGL 普通贴图使用独立精简 shader，由硬件完成采样寻址和插值；保留文字、HSL、生成纹理的特殊处理，不依赖GL3.3采样器对象。
- 关闭自定义缩放时不创建中间纹理；修复 Windows 空闲状态下无法返回消息泵的未响应。
- 临时生产插桩与正常播放诊断已清理；错误报告和独立验证工具保留。

## 性能与验证

Windows Vulkan Release/LTO、LP14，用户设定11x，目标100FPS：同源无尽有效374秒、0到20波，平均99.995FPS、100.000Hz，进程CPU单核占用57.888%，5.789ms CPU/绘制帧。单次观测，不是逐帧GPU计时或功耗结论。完整原理、微基准及原版对照见[性能文档](../perf-fix-ledger.md)。

图集布局编译缓存随源码仓库保留在 assets/definitions/atlas-cache；运行游戏不需要另行安装缓存。
