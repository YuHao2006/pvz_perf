# 钱币、阳光、磁铁与老虎机的时间求值

日期：2026-10-24。依据当前 C++ 源码。已实现老虎机相位与钱币/阳光拾取的时间求值；
磁铁已接入反平方加速度的离线采样曲线。钱币下落仍仅分析公式，
蜗牛按用户决定保留追踪式累加。

## 钱币与阳光

可以按状态起点和整数纳秒时间求值。现有 `TodAnimateCurveNs` 已接受整数纳秒，
线性移动、缩放、奖品现有的曲线可直接使用；匀加速、阻尼、吸附可用对应公式，
不必强塞进已有 easing 枚举。

令 `u=elapsedNs/10'000'000.0`，仅为求值时的无量纲时间比例，保存的仍是整数纳秒。

| 运动 | 可直接求值的公式 |
| --- | --- |
| 天降阳光 | `y=y0+vy*u`，当前 vy 为 0.67 或 0.33 |
| 植物吐出的阳光、弹出的钱币 | 水平匀速；垂直当前先移动再加速度，对齐原版整数步理想递推可用 `y=y0+vy0*u+a*u*(u-1)/2`，`vy=vy0+a*u`，a 为 0.09 或 0.15 |
| 礼物飞出的 0.95 阻尼 | 原版先移动再衰减的几何级数为 `x=x0+vx0*(1-0.95^u)/(1-0.95)` |
| 拾取飞向固定目标 | `P=target+(P0-target)*(20/21)^u` |
| 关卡奖品 | 已按 `TodAnimateCurveNs` 从时间求位置与缩放 |

非整数 u 采用这些理想离散递推的时间延拓；不逐位复现逐步 float 舍入。
连续匀加速物理式中的重力项是 `a*u*u/2`，不能与先移动后加速的离散延拓混称。
碰墙、落地、目标栏切换需要分段重绑定；碰撞随机速度仅在事件采样一次。
落地需计算轨迹与地面相交时刻，不能继续沿用不随步长缩放的“y+vy”预测。
拾取已有 `mCollectX/Y` 起点；普通飞行还需确定初始位置、速度的保存方案。

## 普通磁铁的旧公式

替换前，`Plant::UpdateMagnetShroom` 在距离大于 20 时执行：

```text
P += (target-P)*0.05*(deltaNs/10ms)
```

固定目标下方向不变。d 为距离、t 为秒，连续速度模型及其解为：

```text
dd/dt = -5*d
d(t) = d0*exp(-5*t)
P(t) = target+(P0-target)*exp(-5*t)
```

这是可分离变量的一阶微分方程。若优先保留原版 100Hz 理想离散采样点，
用 `d(t)=d0*0.95^(100*t)`，它与 `exp(-5*t)` 略有不同。
到达 20 的时间分别为 `ln(d0/20)/5` 与 `ln(20/d0)/(100*ln(0.95))`，
无需等待指数趋近零。

## 金磁铁的旧公式

`Plant::UpdateGoldMagnetShroom` 的倍率经过线性曲线夹紧：

```text
k(d) = 0.02                   d >= 30
       0.05-0.001*d           20 <= d < 30
```

每 10ms 的像素速度是 `d*k(d)`；d<20 时发放金币并释放物件槽。
例如 d=100 时移动 2 像素；d=30 或 20 时约 0.6 像素；d=25 时约 0.625 像素。
连续模型可分段解析求解：

```text
远端：dd/dt=-2*d
      d(t)=d0*exp(-2*t)
近端：dd/dt=-5*d+0.1*d*d
      d(t)=50/[1+(50/d0-1)*exp(5*t)]
```

近端仅用于 20～30。从更远处出发，先运行远端 `ln(d0/30)/2` 秒，
再以 d0=30 进入近端；30 到 20 耗时 `ln(2.25)/5` 秒，约 0.162186 秒。
固定初始方向与剩余距离即可恢复 XY。

当前 100Hz 近端离散递推是 `d_next=0.95*d+0.001*d*d`；
上述连续解不是它的精确离散解。目标移动则需重绑定或继续追踪积分。

## 新策划：加速度与距离平方成反比

用户已明确修正：采用的是向内加速度 `a(r)=K/r²`，不是速度 `v(r)=K/r²`。
前面两个磁铁章节记录替换前的行为；下述模型已替换普通磁铁和金磁铁的吸附位置计算。

设固定吸附目标到物体的距离为 r，初距 r0，初始向内速度 v0，K>0：

```text
r'' = -K/r²
r' = -v
v² = v0² + 2K*(1/r - 1/r0)
```

最后一式由二阶方程乘以 r' 后积分得到，是能量积分。
按从静止开始 v0=0：

```text
v(r) = sqrt(2K*(1/r - 1/r0))
t(r) = sqrt(r0³/(2K)) *
       [acos(sqrt(r/r0)) + sqrt((r/r0)*(1-r/r0))]
```

也可以不在运行时反解，而用单调参数 θ 离线生成表：

```text
r(θ) = r0*cos²θ
t(θ) = sqrt(r0³/(2K)) * (θ + sinθ*cosθ)
0 <= θ <= π/2
```

令 T0 为落到中心的时间，则：

```text
T0 = π/2 * sqrt(r0³/(2K))
u = t/T0 = 2/π*(θ+sinθ*cosθ)
r/r0 = cos²θ
P(t) = target + (P0-target)*(r/r0)
```

归一化轨迹只需一份采样表，可以把参数反解、三角函数等放在离线建表阶段。
这不是指数函数，不能直接使用 `TodExponentialCurve<Base>` 的指数表；
可以复用“离线采样、时间定位、线性插值”的实现方式。
若初速度非零或目标移动，需要相应扩展，不能直接套静止、固定目标的表。

实际吸附在半径 R（当前 20 像素）结束，取 T=t(R)，不运行至 r=0 的奇点。
给定期望到达时间 T 时，可反求动画强度：

```text
q = R/r0
F(q) = acos(sqrt(q)) + sqrt(q*(1-q))
K = r0³*F(q)²/(2*T²)
```

若全物品共用固定 K，落到中心的时间随 r0^(3/2) 增长；
初距扩大 3 倍，时间约扩大 5.196 倍，不能误当作只换一条 easing 曲线。
可按每次吸附的期望时长反求 K，让形状改变而完成时刻可控。

### 业务耦合

- 普通磁铁在 `MagnetShroomAttactItem` 开始时就清除护甲、盾牌或特殊物件；
  冷却按动画状态和 `mStateCountdown` 推进，不以飞行物到达距离决定。
- 金磁铁在 `GoldMagnetFindTargets` 把原 Coin 移入 Plant 的 MagnetItem 槽后删除 Coin；
  `UpdateGoldMagnetShroom` 到距离小于 20 时才入账并释放槽位。
  动画结束且没有在途物件后，才启动下一段随机冷却。
- 因此直接替换两者的位置公式，不能宣称对金磁铁玩法无影响。
  用户已接受金磁铁经济节奏随吸附加快而变化，当前入账、槽位释放仍在到达时发生，
  下一段冷却仍等待动画结束且没有在途物件；普通磁铁不改为等待到达再启动恢复。

### 已接入的采样与调参

`MagnetMotion.h` 使用 `K=1,000,000,000 px³/s²`，捕获半径 20px。
800px 初距的中心到达时间约 795ms；更远距离的中心到达时间上限为 900ms，
等效于为该次飞行提高 K，因此任意有效初距的曲线均在一秒内结束。
捕获半径内立即捕获。业务事件仍在下一次实际执行的更新中处理，
暂停或外层更新间隔本身超过一秒时，不承诺现实时间内一秒完成。

`tools/generate_magnet_curve.py` 离线反解归一化时间，生成 4097 个 double
采样点（约 32KiB 只读数据），支持 `--check` 核对产物。
吸取开始时计算起始相对向量、捕获比例及整数纳秒时长；
后续从批次整数纳秒直接查相邻样本并插值，无运行时三角函数、pow 或逐步位置反馈。
double 表避免近静止位置的相邻采样因 float 舍入重合。

每个 `MagnetItem` 新增起始相对向量两个 float、捕获比例 float、中心时长 uint64_t，
当前 native 大小为 40 字节。Plant 新增一个所有同批物件共用的 `mMagnetElapsedNs`，
仅在该植物能力更新时推进；个体能力暂停时也停止，恢复后无需补算暂停时间。
字段语义已在 Plant.h 就地注释。

开发中 Plant 精确状态尾段从 48 扩为 156 字节：原 48 字节后是 8 字节批次时间，
再是五份各 20 字节的物件初始状态。历史物件的前 20 字节按项映射，
避免 native 步长增大后遗漏原有位置和物件类型。
按用户约定不兼容中间开发布局，最终格式与转换器待整体结束统一处理。
附带完美存档的关卡数据需同步重建；用户正在使用的数据目录不自动覆盖。

## 已实现的老虎机相位

删除 `SeedPacket::mSlotMachiningPosition`，复用现有 `mSlotMachineCountDown`
保存整数纳秒剩余时间。绘制和翻页边界从时间采样，不新增独立时钟。
`SlotMachineMotion.h` 提供运算公式，不是字段访问包装。

原逻辑从 3 秒倒计时启动，以 4 秒速度区间得到初速度 5 次/秒，
前三秒线性减至 2 次/秒，再按 2 次/秒完成当前翻页。积分为：

```text
turns(t)=5*t-t*t/2             0 <= t <= 3
         10.5+2*(t-3)         3 < t <= 3.25
```

统一在 3.25 秒、第 11 次翻页边界结束。旧 100Hz 右端点求和前三秒是 10.485 次，
连续延拓在 3.2575 秒完成，实际通常在 3.26 秒的更新结束。
新积分方案通常提前 10ms，不宣称逐位保持旧速度求和。
更新逐个处理跨越的翻页边界，保持大步长内的种子随机选择次数。

历史存档 float 槽由写出投影计算，运行时权威状态只需原有整数纳秒倒计时，
也覆盖 SeedBank 内嵌种子包。当前为开发中语义；正式存档依此前约定，
待整体改造完成统一命名为 v4。

## 编译期指数采样模板与拾取接入

按用户指定采用 10ms 采样、间隔内线性插值。接口为：

```cpp
TodExponentialCurve<20.0 / 21.0>(elapsedNs); // 拾取后剩余位移比例
TodExponentialCurve<0.95>(elapsedNs);       // 每 10ms 衰减 5% 的曲线
```

底数是每 10ms 的乘数，参数是非负整数纳秒，结果是 double。
第 n 个样本为 Base^n，0ns 为 1；15ms 在 Base 与 Base² 间线性插值。
模板定义在 `pvzPerf/Sexy.TodLib/ExponentialCurve.h`。
编译期循环乘法生成 `static constexpr` 表，没有运行时 pow/exp、堆分配、
加载期初始化或对象内缓存。底数必须为有限正数。

每个底数使用 257 个连续采样点和 64 个长区间倍率，共 2568 字节常量数据
（底数 1 的返回值可直接折叠）。普通拾取处于第一段，只查相邻两个采样点。
超过 2.56 秒时按预计算倍率组合，不在表尾夹紧；长时间衰减自然下溢为 0，
增长曲线超出 double 范围返回正无穷。

Base=20/21 时，10ms 内线性插值相对精确指数的最大误差约为 0.0298%。
这是单次曲线逼近，不是逐步累积误差；初距 800 像素时位置误差上界约 0.24 像素。
10ms 采样点与理想指数一致至 double 舍入，不逐位复现旧逐步 float 坐标累加。

`Coin::UpdateCollected` 使用现有 `mCollectX/Y` 起点和
`mDisappearCounter` 的整数纳秒值计算当前位置。
后一个字段在该拾取状态原本闲置，与地面消失计时、奖品计时互斥；
进入普通拾取时归零。没有增加字段或扩大存档记录。
字段复用是因为状态互斥、现有数据足够，不是为了维持开发中存档布局。
若运行时确实需要新字段可直接调整，转换器待最终格式确定后统一处理。
根据当前目标重建上次位置，与实际位置不符时，从当前位置重新绑定起点与时间，
覆盖商店/禅境花园/戴夫目标切换、外部改位及历史状态的重新接入。

### 拾取中对象的存档

`SaveGame.cpp` 把整个 Coin 池交给 `SyncDat64DataArray`，没有按
`mIsBeingCollected` 排除对象。Coin 映射包含当前坐标、拾取起点、
`mIsBeingCollected`、计时字段、类型与附件 ID；读档后重绑 App/Board 指针。
所以鼠标拾取中仍在飞行的金币、阳光会保存，native 往返续跑已有测试覆盖。
字段复用的状态、单位和归零点已在 Coin.h 与 Coin.cpp 就地注释。

金磁铁吸走的金币是另一种情况：原 Coin 已删除，飞行中的物件记录在
Plant::mMagnetItems 中；该数组也在 Plant 的存档映射中。

原版根据移动前的距离判断入账、缩放和透明度；当前用 `max(elapsedNs-10ms,0)`
的曲线距离保留这一语义，不再依赖“上次实际更新”。
原版 1073 固定目标下，阳光距离小于 8、钱币小于 12 后立即入账并删除；
400 像素初距在 100Hz 下分别于第 82、73 次更新完成。
其他步长在当前更新中检查时间采样结果，结束事件仍受外层更新时刻量化。

独立算术基准位于 `Tests/performance/exponential_curve_benchmark.cpp`。
本机 Core Ultra 9 185H、MSVC 14.51、/O2 /Ob2，固定逻辑处理器；
8192 个固定种子的 0～1.2 秒输入，每次 200 万次求值，轮换测量顺序，
每种取 5 次中位数。CPU 未锁频，按用户要求不把本轮耗时写入文档；
结果仅留临时输出，待受控条件下复测。
基准核对了相对误差上界并输出累计结果，未加 volatile。
该基准只测曲线内核，不用于推断整帧或整个 Coin 更新的加速比例；
起点重绑定检查、坐标采样和距离计算仍有成本。
自定义基准源码保留在项目，产物与日志放系统 Temp。
