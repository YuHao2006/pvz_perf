# v4.0.3 网页音乐启动修补

本修补基于 v4.0.3，原生四个包与存档格式不变。

- 点击开始后，音乐初始化及 MO3 实例装载共用最多 30 秒预算；正常准备完成立即继续。
- 由解码线程确认 MO3 已装载，不再把只投递了 load 命令当作加载完成。
- 超时静默继续游戏，保留音效与正在初始化的音乐图。晚到的播放器按顺序接收 load／seek／音量／播放命令，无需刷新即可恢复。
- 解码器不可用或真正处理失败仍保持游戏和音效可用。退出时取消等待，新会话可以重试。
- 关卡备份提示改为在“高级选项”导出。

验证见 `Tests/evidence/web-music-startup-20261114`。本机浏览器通过；尚无新的手机 B 站宿主实机验证。
