# main：标准对话框离线烘焙（v4.0.4）

状态：**已实施并通过 Vulkan／OpenGL 图像回归**。这是此前 `dialog_bottomleft` / `dialog_bigbottomleft` 待办的 main 实现，不使用高清分支、Spine 或 ReReanim 数据，不修改存档格式。

原版底块尺寸为 107×112／107×148；右块与中块分别为 114／150 高，比左块多 2 像素。`CalcSize`、`Resize` 及按钮定位继续使用原尺寸。离线合成的两张底图为 320×265 和 320×301，运行时最多九区绘制，四角和底座保持尺寸，只延展内部及直边；顶部标题装饰仍单独绘制。保留原绘制多出的 2 像素边缘，不把高底座压成普通底座。

没有开框时创建纹理、渲染目标或按对话框尺寸增长的缓存。两个 PNG 的源 RGBA 共 724,480 字节，统一打进已有 CommonUI 图集，没有新增纹理绑定。原拼块仍用于布局尺寸和对照，不另建运行时缓存。

测量（同一 main 资源集）：CommonUI 从 222×1011／897,768 字节变为 1090×380／1,656,800 字节，增加 759,032 字节（约 741 KiB）。整个 PAK64 增加 47,711 字节；该包同时包含图鉴修复涉及的绑定重建，不能把这项差值全部归因于对话框 PNG。常见 506 宽、三个中间行的背景从 25 个矩形降至 9 个；692 宽同高度从 35 个降至 9 个。它们原本就在同一图集中，不能宣称 draw call 等比例下降。

验证覆盖普通／高底座、320／506／692 三种宽度、最小高度、长文本和双按钮。320 宽的基准尺寸与旧拼接逐像素对拍，其他尺寸检查原四角、底座及按钮位置。图像输出在 `out/verification/v404-water-dialog/`。宽屏图鉴检查同时覆盖 800／1400 宽度。中部旧纹理纹样会随适配区域延展；不是整框非等比缩放。

重生成工具位于独立工具仓库 `tools/bake-standard-dialogs.py`。它是修改源素材时的一次性离线制作工具；正式资源构建直接读取 PNG，仍只运行 C++ 工具。
