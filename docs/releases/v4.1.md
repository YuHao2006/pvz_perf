# v4.1 高清版

本次从高清分支发布两个现代 Vulkan 原生包，均携带 **2× PAK64**。高清网页版暂缓发布，本次不提供高清网页运行时或网页附件，也不设置普通版网页中的高清跳转链接。

- 接入已审核的高清 UI、场地、植物、僵尸、动画组件和粒子素材，优先复用重植版素材；保留经用户确认的原版修复方案。
- 包含已批准的巨人青筋与关节、小鬼、卷心菜／玉米投手、投篮车、硬币侧面与背面、智慧树、泳池、成就接缝、菜单按钮和大头贴修正。
- 保留原版动作时长和游戏逻辑；必要的素材支点、关节与绘制顺序修正已离线落入定义。未采用废弃的 ReReanim 试验。
- 2× 图集从已认证的 4× 图集整页缩半，不重新装箱，不改变归一化 UV 或逻辑尺寸。透明图使用 PNG；不透明图片使用已批准的 JPEG95 4:4:4 导出，并由无损母图直接生成 2×，避免重复 JPEG 压缩。本包不是轻有损／调色板实验包。
- 包含 Windows 中文路径效果文件读取修复、图鉴入口僵尸脚底阴影和 Credits 泳池闪光等本轮共用修复。
- 完美存档和无尽基准随包提供；存档仍为 DAT64 v5.1／schema `0x10747`，用户资料格式不变，可与普通版互通。首次运行前建议备份现有存档。

## 包与系统要求

| 包 | 要求 |
| --- | --- |
| x64-win10-vulkan1.3 | Windows 10 x64、Vulkan 1.3 及相应特性 |
| arm64-android14-vulkan1.3 | Android 14、Armv9-A、Vulkan 1.3 及相应特性 |

高清版不提供 OpenGL、Windows 7 或 Android 7／Vulkan 1.0 兼容包；低端兼容平台请使用普通版。

请完整解压 Windows 包或安装对应 APK，程序、PAK64、shader 和 DFU 必须成套使用。Android 与普通版使用相同应用标识和签名，请先备份后覆盖安装；这不提供两个独立安装的应用。

## 显存与已知限制

**高清分支尚未实现按场景动态加载／卸载高清纹理，也没有完整显存预算管理。** 2× 仅降低纹理像素量，不能据压缩包大小判断实际显存峰值；低显存设备仍可能出现明显掉帧。详细策略见本分支的 [高清资源加载说明](../high-resolution/resource-loading.md)。本次不宣称 Android／Windows 7 实机性能已验证。

源码仓库不包含图片素材；生成的 C++ 和布局缓存保留。完整发行包包含运行所需资源。

## 已知未解决问题：UHD 630 的 Vulkan 低帧

已有用户反馈 i5-10500／Intel UHD 630 在普通版中 Vulkan 可进入游戏，但帧率异常低；其同机 OpenGL 版本约90帧。反馈未完成同版本、同存档和同设置的受控复测，不能据此量化所有设备的差距。此前设备选择修复不等于根因已查明，该问题目前仍未确认修复。

v4.1 仅提供现代 Vulkan 包，不包含 OpenGL 兜底；已受影响设备请暂用普通版 OpenGL。驱动宣称支持某个 Vulkan 版本也不代表该性能问题不存在。本版不宣称已经解决 UHD 630 的低帧问题。
