# 石牌共用底图的两种状态

五组石牌的高亮态由已经通过的普通态派生，没有重新绘制几何形状或重采样普通态。两态 alpha 完全相同，暗色刻字和外轮廓 RGB 保持不变。亮度变化参考原版同组图片的 `highlight - normal` 差值；差值双线性放大后只作用于颜色，所有处理离线完成。

当前运行图以既有 2 倍普通态为基准。4 倍配对资源独立按同一颜色配方生成：Puzzle、Survival 使用之前保存的 4 倍母版；另外三组以已经通过的 2 倍成品整理为 4 倍画布，同时保留了更高分辨率的原始 AI 输出。后续制作真正的 4 倍版时，后三组应回到这些原始 AI 输出重新整理，不能把放大后的 2 倍画面当作新增细节。

`manifest.json` 记录每组来源、实际尺寸、校验值、母版基准与两态一致性检查。旧的独立生成高亮素材仍保存在此前的素材修复目录及 Git 历史中。
