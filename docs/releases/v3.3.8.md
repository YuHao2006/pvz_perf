# v3.3.8

本次为兼容修复更新，继续使用 DAT64 v4／schema `0x10745`，可读取现有 v4 存档。v5 改造暂缓。

## 游戏修复

- 普通出怪改用关卡时钟上的预期刷新时间：普通间隔为25～31秒，达到血线后缩短到2秒。大波预告与实际刷新分别计时，修复可变步长下红字后过快刷新、轮次提前结束的问题。
- 读写存档时沿用原字段的剩余纳秒表示，在读档后重建预期时间；不改变存档布局。
- 修复夜晚高潮音乐进入释放阶段时读取旧倒计时，导致高潮声部立即归零的静音问题。共享音乐逻辑同时覆盖原生与网页。
- 横板 UI 的铲子紧排在实际卡槽后，传送带按完整容量定位；鼠标与触控共用命中区域。
- 横板 UI 关闭卡牌鼠标悬停提示，桌面布局保持原行为。

## 网页及存档工具

- 自定义存档完全脱离游戏运行模块。独立 wasm32 转换器处理格式校验与读写，JavaScript 负责编辑、布阵和界面；无需启动游戏、图形接口、音频或加载游戏资源包。
- 修复部分宿主已解压 gzip 内容后，工具再次解压造成的 `Failed to fetch`。生成所需模板随工具脚本打包，消除单独模板请求。
- 冒险模式统一使用 `game<ID>_0.dat64` 槽位，关卡从目标用户的冒险进度读取；删除无意义的重复关卡输入框。生成关卡不会修改用户进度。
- 保留 wasm32／wasm64 与 WebGL 2／WebGPU 四运行时，共用设置、资源和存档。独立存档工具始终使用 wasm32。
- 工具源码见 [PvzDevTools](https://github.com/YuHao2006/PvzDevTools)，游戏仓库仅附带构建后的工具。

## 验证与下载

已执行可变步长出怪、夜晚音乐、横板铲子命中、独立工具转换／生成／编辑回归。生成器覆盖六场景及多模式，验证未访问游戏模块、图形或音频。B站 gzip 重复解压问题已在实际地址复现。

提供 Windows 10／Vulkan 1.3、Windows 7／OpenGL 3.3、Android 14／Vulkan 1.3、Android 7／Vulkan 1.0 和网页版，并附完美存档与无尽基准。请成套更新程序和资源。未新增旧设备实机覆盖，不将桌面自动化测试等同于全部浏览器或手机验证。
