# v4.1.4 高清版改动

- 小游戏、解谜和生存页的奖杯与计数随标题石牌的右端移动。拉宽窗口时，二者保留原版 800 宽画面中的右边距。

- 高清版按 `main.pak64` 内的 `compiled/render-height.txt` 决定场景高度。1200p 包绘制 1200 行，2400p 包绘制 2400 行，再用双线性采样把完整画面缩放到窗口。场景宽度随游戏视口比例调整。
- 动画和粒子图集按 PNG 的实际像素尺寸上传，沿用打包时生成的归一化 UV。字体按包内声明的逻辑尺寸计算字形 UV。修复 600p 实验包在开屏加载 `loadbar_sprout` 时退出的问题。
- Windows 版支持拖动窗口边框调整大小，并记住上次的客户区尺寸。首次启动默认 1920×1200 物理像素。Vulkan 标题栏按“场景 → 窗口”显示两者的实际像素尺寸。
- Vulkan 对请求平滑过滤的绘制使用双线性采样，减轻 reanim 缓慢浮动时斜边和黑色轮廓上的波纹。受颜色滤镜影响的透明边缘按相邻纹素计算颜色后再插值。
- 开屏和冒险片头的《Plants vs. Zombies》标题恢复原版的柔和阴影，保留高清字面、描边和原有透明度渐变。
- 失败动画「The Zombies Ate Your Brains!」恢复字母内孔、笔画间隙和外轮廓的透明度。底色能正常透出，绿色字面和黏液飞溅的颜色保持原样。
- 普通豌豆、寒冰、双发、反向双发和裂荚射手的单茎向头部延长，茎根仍固定在原处，修复待机和射击时头下露出背景色的细缝。寒冰射手沿用 v4.1.3 的嘴部上移 0.5 个逻辑像素。
- Windows 鼠标悬停改用 `GetCursorPos` 按逻辑更新采样。只剩鼠标移动时，消息泵提前返回，混合输入每轮最多处理 32 条。
- Windows 无尽基准图新增平均 FPS 和平均每绘制帧 CPU 时间两条带数值的虚线，仅统计前台有效战斗区间。

## 下载

Windows 10 与 Android 14 的 Vulkan 1.3 完整包各有 1200p 和 2400p 两种，随网盘分发。GitHub 提供程序包、Windows PDB、Android 函数地址表、完美存档和无尽基准。Windows 程序包需搭配同版本高清 `main.pak64`；Android 请使用网盘完整 APK。高清 Toy 完整包使用 1200p 资源。
