# 高清分支的 v4.0.3 基线

本分支 `high-resolution-v4.0.3` 直接从普通版 v4.0.3（`39f9c228`）建立。原高清分支与其本地审核结果保留在 `high-resolution` 的 `7e123c10` 检查点；四倍母图及未入库审核工作文件仍留在原工作目录。

迁移保留已审核的两倍像素素材、字体指标、Reanim 定义修正和高清 UI 绘制。普通版的可变步长修复、Vulkan 设备选择、全局独立纹理表和临时战斗卡牌图集从 v4.0.3 基线继承。临时卡牌图集使用两倍像素绘制目标，避免把高清卡牌缓存成低分辨率。

高清图鉴已经使用独立纸面、装饰与边框，保留这一绘制方式；未套用只接受普通版几何尺寸的 `compact_ui` 离线合成。图鉴预览地面复用地图。没有引入新的未经审核 Reanim／Particle 部件，也没有改变存档字段。

普通版发行仍在 main；本分支是高清开发分支，不是新的高清正式发行。
