# v3.2

此提交是多线程试验前的稳定回退点，正式运行仍为单线程更新。

目标帧率最低30。模拟按steady_clock实际经过的整数纳秒一次更新，取消10ms上限与补拍循环。超时的节拍余量缩短下一次等待，不重复计入模拟；未到期时间保留。暂停／恢复重建墙钟基准。低刷新率、倍速和长卡顿可能改变离散积分及碰撞结果。

Reanimation使用整数除模跨关键帧，同一更新时间的帧时间和根位移查询复用缓存，倒放、seek和端点行为保留。Vulkan使用两套逐帧命令／动态顶点资源，纹理与图集共享；水波变换回CPU，焦散使用整数纳秒相位。修复1073对照确认的无尽选卡冻结边界及选卡水面闪光时钟。

存档仍为DAT64 v4，字段布局不变；不改变已有存档的时间锚点语义。程序、资源包与shader应同树使用。历史v3.1文档保留发行时行为说明。

验证结果及试验边界见runtime.md、validation.md与Tests/evidence。多线程候选必须在此提交之后单独记录，不计入本版收益。
