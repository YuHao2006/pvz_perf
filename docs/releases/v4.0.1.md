# v4.0.1

本版修复提示文字的时间与动画问题，存档格式继续使用 DAT64 v5.1 / schema `0x10747`，与 v4.0.0 兼容。旧 DAT64 v4 的独立 DFU 自动升级行为不变。

## fixed 补包：存档编辑器

版本号保持 4.0.1，只更新网页版内附的存档编辑器。保存用户进度时，额外卡槽购买次数限制为 0～4，对应总共 6～10 个卡槽，并明确标注含义。实际保存时把超范围整数钳制到 0～4，保存后界面显示实际值；非整数不允许保存。

游戏运行时、读档行为、存档格式及四个原生发行包均保持原样。原 v4.0.1 标签保留；编辑器修复源码位于主分支后续提交及其标明的 PvzDevTools 提交。

## 已修复

- 提示时长在纳秒迁移时被重复换算，导致有限提示被当成常驻提示。恢复原版的 2.5 / 5 / 7.5 / 15 秒时长，真正的常驻教学提示保持常驻。
- 恢复老虎机的提示循环：拉杆清掉当前提示，结果提示到期后重新显示 “Spin Again!”；没有增加拉杆或出怪业务分支。
- 修复 “A HUGE WAVE OF ZOMBIES IS APPROACHING!” 字母的入场、拉伸与退场时序。字母动画使用提示管理者传入的关卡时间，避免暂停期间 visual 时间推进导致恢复时跳到末帧。
- 恢复 username’s House 开场标题在创建后按开场 visual 时间显示 2.5 秒后消失。

- 修复 Memory64 网页在刷新／离开页面时，Emscripten beforeunload 回调将 BigInt 字符串指针直接传入 UTF8ToString 的类型错误。仅修正网页宿主桥接，不修改游戏逻辑或字符串热路径。

## 网页音频诊断

新增可选诊断字段：总音量、各曲目音量、播放/暂停状态、音频线程错误与同步状态。仅在用户启用诊断或主动导出时读取现有缓存，不增加每帧采样或音频同步等待。

未确定来源的静音反馈尚未复现，本版不宣称修复了新的静音问题。已复查共享高潮控制、桌面实际 BASS 播放和网页实际 MO3 解码，昼夜切换、淡出、重触发、暂停恢复等回归通过。

## 发行包与存档

四个原生包：x64-win10-vulkan1.3、x64-win7-openGL3.3、arm64-android14-vulkan1.3、arm64-android7-vulkan1.0；网页版继续包含 wasm32/wasm64 × WebGPU/WebGL 2 四种游戏运行时，以及独立 wasm32 存档工具。

B站包正常 Quit/资料回写后自动备份用户进度、花园和阵型库。**关卡 DAT64 不上传云端，只保存在当前浏览器，须自行导出备份。** 设置页保留常驻提醒与上传中的红字提示。

附带完美存档（含坚果包扎术）、同源原版起点转换的无尽基准与文件校验清单。资源和着色器内容相对 v4.0.0 不变，本版不宣称新的性能提升。
