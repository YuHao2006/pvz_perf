# main：蒙版合并撤回，大头贴 UI 烘焙保留

更新日期：2026-11-17。**当前已撤回 RES-01 的透明蒙版合并，保留 RES-02 大头贴固定 UI 烘焙及 PERF-01 图鉴按需焦散更新。** 不修改存档格式，不影响高清分支的 JPEG 构建导出。

## 透明蒙版恢复原路径

普通版继续使用原 JPG／PNG＋外置透明蒙版，恢复原资源绑定、`alphaimage`／`alphagrid` 和自动 alpha 查找设置。移除合并实验生成的活动 PNG，恢复原图及蒙版的原始字节。字体和特效的功能性遮罩也继续保留。

回退原因：已发布普通版 v4.0.4 的 B站 ZIP 为49,591,037字节，按50,000,000字节预算只余408,963字节。合并实验即使保留不透明JPG，开发PAK仍由39,477,052增至40,936,757字节。主要增长来自原有损JPG加蒙版转为无损RGBA PNG；本轮优先保留包体余量，不再默认推进这项转换。

原始图片和合并实验配方仍在本地 `assets/source-art/archive/main-resource-cleanup-20261117/`；[迁移索引](../assets/source-art/main-resource-cleanup-20261117.json)已标记撤回，不能再把实验PNG当作活动构建输入。当前资源绑定见 `assets/definitions/resources.json`。图片不重新加入Git。

## 大头贴固定 UI

原外框、固定内部面板和九个分类按钮常态烘焙进同一张 DISPLAY_WINDOW；正常编辑时不再逐张提交固定面板和常态按钮。WIDGET_BG 的逻辑尺寸仍为 560×493，保持构造和交互布局；其物理像素已并入父底图。

WIDGET_INNER_BG 复用为 509×335 的恢复图：前 499×335 为原有不透明内部底色，右侧 10×335 为分类列与面板重叠条。确认／浏览页恢复原底色；悬停、按下或隐藏分类按钮时，只恢复原分类列及面板重叠条，再按原顺序绘制实时按钮，保留半透明边缘、相邻行覆盖和多个触控接点。头像、物品、颜色、选择高亮及动态控制保持原绘制。

没有新增运行时合成、渲染目标缓存、图片槽或纹理对象。固定图块变少不等于 draw call 等比例减少。图集 RGBA 容量由 112,977,528 增至 113,108,692 字节，增加 131,164 字节（约128 KiB），主要为 UI 状态恢复图；透明度固化本身不改变最终 RGBA 尺寸。

撤回后的本地开发 PAK 为 39,587,202 字节，比原基线增加 110,150 字节；其中大头贴图集增加 108,360 字节。再做无损 PNG 紧凑化后为 39,209,797 字节。没有为本轮额外做有损压缩。

## 验证与发布边界

合并实验期间的历史结果见 `Tests/evidence/main-resource-cleanup-20261117/`，不代表回退后的当前输入。回退后的包体、资源与绘制验证记录在 `Tests/evidence/main-alpha-rollback-20261117/`。

已发布的v4.0.4附件保持原样，不用新候选覆盖旧版。网页候选必须重建与当前生成C++匹配的四套运行时，不能用旧Wasm混装新图集资源。新增用户修复与下一版发行另行安排。
