# v4.0.3

- 修复可变步长跨越事件触发点与结束点时漏掉攻击、爆炸、收集、动画收尾或界面切换的问题，覆盖植物、僵尸、关卡终场、选卡和 Credits 等路径。保留 ICE3／ICE4 的更新顺序。
- 修复传送带关卡入场滑动跨越终点时未完成停靠的问题，包括 5-10。恢复原版生存模式中巨人、冰车等出怪资格的旗数限制。
- 减少重复纹理：Credits 复用地图背景，图鉴背景分层复用并直接绘制已有地图区域，大头贴静态界面离线合成；战斗卡牌按当前卡槽／传送带生成临时图集，在换轮或退出时释放。重绘局部卡牌只更新对应区域。
- Reanim 专用图集仍由各定义持有；独立共享图片改用全局纹理表，普通轨道继续直接访问专用图集。
- Vulkan 在过滤设备能力与窗口呈现支持后，保留加载器的设备顺序，优先选择首个可用硬件设备；移除按纹理上限及显卡类型加分的选择方式。Windows 启动时将实际设备与驱动写入 `log/gpu-device.txt`，便于核对多显卡问题。
- 网页版改用无损压缩资源，保留 WebGL 2／WebGPU 与 wasm32／memory64 四个运行时，以及独立的存档工具。B 站包与离线包使用同一实现，仅平台检查配置不同。

存档仍为 DAT64 v5.1 / schema `0x10747`，可继续读取现有存档。请成套更新程序、资源包、shader 与 DFU；关卡 DAT64 仍不上传云端，需要自行备份。

验证包含多步长事件回归、静态资源加载／释放、临时卡牌图集和 Vulkan 设备选择测试。设备选择已在本机 NVIDIA 显卡验证；尚未取得反馈用户的 UHD 630 实机数据，不能据此认定其低帧问题已解决。
