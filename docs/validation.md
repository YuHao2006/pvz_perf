# 构建与验证边界

本页按验证范围维护当前入口和已确认边界，不按日期追加中间实现。不把历史平台通过状态或已撤回的GPU动画试验当作当前构建验收。

## 当前本机构建与检查

| 范围 | 已执行检查 | 结论边界 |
| --- | --- | --- |
| Windows Vulkan Release | 实际生产编译／链接，/GL与/LTCG核对，PVZ_ENABLE_GAME_PROBES=OFF | 当前可执行文件构建成功，不据此宣称其他平台已实测 |
| Android arm64 Vulkan | NDK Full LTO编译与链接 | 当前库构建成功；装机与设备运行单独验收 |
| 主循环 | FrameTiming及真实Process状态机夹具 | 实际纳秒守恒、10ms上限、欠时保留、短补偿步、补拍后绘制；覆盖低频和10000FPS目标 |
| 存档 | time_counter_save、v7_save_schema，真实原版→v4读写／重载 | 原输入SHA256不变；当前游戏仅直接读取v4 |
| 实际图像与资源 | test-image-runtime.ps1链接生产对象，使用实际PAK | 字体、资源分组、reanim外观、CPU粒子、共享纹理及反复释放通过 |

单元入口：`ctest --test-dir out/x64-win32-vulkan -C Release --output-on-failure`，只运行当前实际构建的目标。不能用旧exe存在来宣称新源码已通过。

## 资源和生命周期

实际图像夹具覆盖29个资源组、398项资源：210个GPU图像、20个具名字体、168项真实声音解码；资源计划完成后丢弃，具名绑定及共享别名正确释放。字体临时位图和图集CPU像素上传后释放。定义图集、特殊字体采样与反馈目标使用各自契约，不把普通图像假设套给所有输入。

静态定义入口为`tools/test-static-definition-runtime.ps1`。它链接当前生产对象，覆盖图集缺失、损坏、尺寸错误的回滚和同进程恢复，并检查真实对象运动及实际Process调度。默认行为和变体共享行为数据，外观仍有独立GPU绑定及UV行。GPU动画常驻、稀疏GPU轨道和公式粒子等旧试验已撤回，不保留其验收开关作为当前必测项。

源资源和发行范围见[资产边界](ASSETS.md)，线性布局、PTC1和NRSC4见[资源格式](RESOURCE-V5-FORMAT.md)。历史ResourceId和原版行为记录只用于离线转换及独立对照。

## 时间、运动和存档

普通物件和粒子按当前有效纳秒步长离散模拟；reanim相位及根运动按共享整数时钟求值。不同步长的碰撞、随机事件、追踪及复杂力场允许差异，不要求全游戏任意分区逐位一致。

主循环检查包含30Hz实际33.345ms的完整单步及下一拍33.321666ms补偿、100Hz实际10.123456ms不截断、目标4ms超时后的短间隔、长卡顿不拆分，以及三种节拍各十万次随机抖动的纳秒总量守恒。最低目标帧率30，默认仍100；不使用10ms补拍。

`tools/test-save-upgrade-runtime.ps1`装载实际资源后读取v4，保存并再次读取，验证对象与外观状态和时间重绑定；输入文件保留原哈希。原版基准源为Tests/game3_13.dat；旧格式经独立转换器显式升级，不能靠改文件名或版本字绕过结构迁移。冻结协议见[存档转换](DAT-DAT64-CONVERSION.md)和标明历史范围的[时间协议](research/dat64-v2-time-audit.md)。

## 绘制和界面

`tools/test-image-runtime.ps1`覆盖实际字体、命名资源、reanim变体及共享矩阵恢复、fullscreen轨道、商店时钟／翻页／暂停恢复、Quit无目标文字计高与释放。种子包冷却分别检查四分之一、一半和四分之三位置，保证灰色遮罩边缘及已恢复区域正确。

CPU粒子绘制按293项原始发射器／变体／裁剪情况与独立CPU参考对拍，其中291项具有可见像素；包括无图粒子、火冰不同尺寸、原始帧动画及重复加载／释放。参考渲染只在测试代码中，生产不增加对拍成本。

Vulkan独立GPU实验将像素正确性、同步校验与timestamp计时分开。历史独立实验结果只支持对应产物和输入，不当作当前完整WSI套件、所有驱动或手机功耗证明。[GPU专项](android-gpu-submission.md)维护合批、16位索引、透明边缘和帧资源复用边界。[GPU泳池](gpu-pool-production.md)维护水波及焦散契约；Windows主机不能代替Linux、Android、macOS及旧API设备验收。

音乐入口`tools/test-music-runtime.ps1`检查实际BASS设备、夜晚高潮声部、音量和暂停恢复；静音或只验证返回值不能替代扬声器听音。Linux OpenAL和其他后端在各自环境单独运行，不能由本机Windows构建成功推断。

## 性能与证据

整局帧率和CPU以[性能优化与测量](perf-fix-ledger.md)的新基线为准；历史算法及固定Draw小指标保留给3.0复测。CPU百分比以单核100%，进程CPU毫秒／绘制帧包含进程内所有线程；一秒样本不能声称逐帧p99或GPU耗时。

Release在自己的目录运行，测量器只读现有计数和进程时间，不注入游戏计时。用户在控制台按Enter开始，3秒后恢复战斗，默认持续到游戏Quit／进程退出，Enter不会提前停止；只有显式-Seconds才限时，采样器不会关闭游戏。采集原始输出写系统Temp，最终精选证据和条件、哈希保存在Tests/evidence，历史对照夹具保存在Tests/reference。Linux25x与Windows11x分别记录，不计算跨条件优化倍率。

功能和采样所需临时文件放Temp，不堆入out。独立实验只编入其专用目标；普通Release不保留临时GPU查询、逐帧工作量计数、纹理创建分段计时或音乐追踪。
