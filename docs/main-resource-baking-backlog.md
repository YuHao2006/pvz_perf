# main：透明蒙版退役与大头贴固定 UI 烘焙

更新日期：2026-11-17。状态：**已实施，最终验证记录见下方；尚未另行发行**。对应统一待办 RES-01、RES-02，见 [main 待办入口](main-backlog.md)。本轮只使用 main 原有素材，不引入高清分支素材，不修改存档格式。

## 透明度离线固化

确实需要透明度的图片，将原解码 RGB 与独立透明蒙版的蓝通道／显式 alpha-grid 离线合并为 RGBA PNG。保留原逻辑尺寸、图片内部黑色和半透明边缘；不能全图删黑。32 个外置透明蒙版源文件从活动运行资源目录退役，包括未进入运行包的历史输入。45 个独立 PNG 输出覆盖实际来源和资源变体，显式资源绑定保留所需不同解码结果。

所有作者图片条目关闭旧式自动蒙版查找，显式 `alphaimage`／`alphagrid` 引用已移除，大头贴图片定义的 `auto_alpha` 均为 false。染色图层、游戏效果遮罩及字体 alpha 保留，它们不属于这里退役的外置透明蒙版。

不透明、无蒙版的 JPG 继续使用原始字节，避免无意义地转成 PNG 放大包体。最初整批转换后已收回 30 个这类 JPG 和 45 份多余 PNG；“透明蒙版退役”不要求所有图片都改格式。

原 JPG、透明蒙版、被改写的源 PNG、旧绑定及合成记录集中保存在本地 `assets/source-art/archive/main-resource-cleanup-20261117/`；活动文件在 `assets/runtime/`。两者都应纳入本地素材备份。当前输入映射与 RGBA 哈希见 [迁移索引](../assets/source-art/main-resource-cleanup-20261117.json)。图片不重新加入 Git。

## 大头贴固定 UI

原外框、固定内部面板和九个分类按钮常态烘焙进同一张 DISPLAY_WINDOW；正常编辑时不再逐张提交固定面板和常态按钮。WIDGET_BG 的逻辑尺寸仍为 560×493，保持构造和交互布局；其物理像素已并入父底图。

WIDGET_INNER_BG 复用为 509×335 的恢复图：前 499×335 为原有不透明内部底色，右侧 10×335 为分类列与面板重叠条。确认／浏览页恢复原底色；悬停、按下或隐藏分类按钮时，只恢复原分类列及面板重叠条，再按原顺序绘制实时按钮，保留半透明边缘、相邻行覆盖和多个触控接点。头像、物品、颜色、选择高亮及动态控制保持原绘制。

没有新增运行时合成、渲染目标缓存、图片槽或纹理对象。固定图块变少不等于 draw call 等比例减少。图集 RGBA 容量由 112,977,528 增至 113,108,692 字节，增加 131,164 字节（约128 KiB），主要为 UI 状态恢复图；透明度固化本身不改变最终 RGBA 尺寸。

本地开发 PAK 由 39,477,052 增至 40,936,757 字节，增加 1,459,705 字节（约3.7%）；这是需要透明度的 JPEG 转 PNG 等输出差异，不是同等增加显存。没有为本轮额外做有损压缩，也不把开发 PAK 的大小当作最终平台发行包大小。

## 验证与发布边界

- 固化前，与原生编译器 445 项解码 RGBA 哈希核对一致。
- 实际 PAK：205 项活动图片解码配方的外置透明蒙版引用和自动查找标志均为 0；退役透明蒙版没有进入包。
- 204 张可从旧／新 PAK 独立解码的图片，RGBA 完全一致；另一个是仅由透明占位蒙版生成的 blank。
- 2148 张图集图片哈希未变，预期变化仅为大头贴整页与恢复图。
- 45 项新 PNG 通过实际平台 PNG 解码与未改动原始输入重建的编译器色值基准对拍。旧运行时使用 JPEGli，和资源编译器／Pillow 的 JPEG 解码存在差异；本轮以资源编译器色值统一 PNG，不能宣称与旧 JPEGli 路径逐像素一致。调查中全源图每通道最大差异为34，JPEG 灰度透明蒙版的最大 alpha 差异为7；这不影响上述旧图集哈希一致的结论。
- 图鉴、标准对话框与大头贴的 Vulkan／OpenGL GPU 回归结果归档至 `Tests/evidence/main-resource-cleanup-20261117/`。大头贴对照原始素材和实际旧式绘制，覆盖普通、悬停、按下、多点接触、隐藏按钮、确认与浏览；确认页比较区域排除另行绘制的动态文字。

自动回归不替代用户手测；不修改已发布 v4.0.4 的附件，也未新增 Android、Win7 实机或手机浏览器验收。
