# 1073 图鉴水面、焦散与水面闪光

核对日期：2026-11-15。以本机 GOTY 1.2.0.1073 原程序为准，SHA256 为 `5f650f52d12751e08b63e590edb0d9b9f09d087cea900baa0eb39e4af8eda251`。反编译参考项目内的旧地址注释属于另一布局，以下地址已用原程序逐条校验。证据位于 `Tests/evidence/almanac-water-1073-20261115/`。

## 原版行为

- 图鉴 Update 位于 `0x402F50`；`0x403089` 对共用 PoolEffect 的 `+0xC` 计数递增，没有按当前图鉴页面分支。
- 植物页位于 `0x403290`。睡莲 0x10、水草 0x13、猫尾草 0x2B 和海蘑菇 0x18 使用泳池预览；最后一个使用夜间资源。
- 植物页先画静态 GroundPool／GroundNightPool。开启 3D 加速时再调整裁剪及 Y 偏移，在 `0x4035E2` 调用 `PoolEffectDraw(0x46E180)`。
- PoolEffectDraw 的 3D 路径绘制 base、shading、caustic 三层。`0x46E994` 调用 `UpdateWaterEffect(0x46E040)`，在绘制时重算 128×64 焦散图；夜间焦散更淡。2D 路径直接画静态池水，图鉴也不会进入动态水面绘制。
- 水面星点 `PARTICLE_POOL_SPARKLY` 是 Board 的独立粒子，由白天泳池关卡创建。Almanac 没有创建／拥有这套粒子，也没有把暂停战场的池面粒子搬进预览。

## v4.0.4 当前行为

图鉴水生植物仍绘制三层动态水面，焦散在 GPU 上生成共享的 128×64 结果，不使用 CPU 像素循环，也不为图鉴创建另一套焦散纹理。图鉴没有新增水面闪光粒子，与原版相符。

有一处可避免的额外工作：Almanac 每次 Update 都调用 PoolEffectUpdate，而后者在有效时间推进时会标记 GPU 焦散待生成；Vulkan／OpenGL／WebGPU 在下一帧开始时执行。因此当前浏览图鉴索引、僵尸或非水生植物，也可能执行这张小纹理的更新。原版这些页面只推进计数，焦散生成留到水生植物实际绘制时才发生。

本次仅核对并记录，保留用户刚手测通过的 v4.0.4 程序。后续若优化，应保留时间相位推进，将焦散生成延迟到实际使用时；不能直接停掉非水生页面的时间推进，也不能添加原版不存在的池面闪光粒子。
