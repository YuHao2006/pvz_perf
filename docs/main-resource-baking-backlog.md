## 大头贴固定 UI

原外框、固定内部面板和九个分类按钮常态烘焙进同一张 DISPLAY_WINDOW；正常编辑时不再逐张提交固定面板和常态按钮。WIDGET_BG 的逻辑尺寸仍为 560×493，保持构造和交互布局；其物理像素已并入父底图。

WIDGET_INNER_BG 复用为 509×335 的恢复图：前 499×335 为原有不透明内部底色，右侧 10×335 为分类列与面板重叠条。确认／浏览页恢复原底色；悬停、按下或隐藏分类按钮时，只恢复原分类列及面板重叠条，再按原顺序绘制实时按钮，保留半透明边缘、相邻行覆盖和多个触控接点。头像、物品、颜色、选择高亮及动态控制保持原绘制。

没有新增运行时合成、渲染目标缓存、图片槽或纹理对象。固定图块变少不等于 draw call 等比例减少。图集 RGBA 容量由 112,977,528 增至 113,108,692 字节，增加 131,164 字节（约128 KiB），主要为 UI 状态恢复图；透明度固化本身不改变最终 RGBA 尺寸。

撤回后的本地开发 PAK 为 39,587,202 字节，比原基线增加 110,150 字节；其中大头贴图集增加 108,360 字节。再做无损 PNG 紧凑化后为 39,209,797 字节。没有为本轮额外做有损压缩。
