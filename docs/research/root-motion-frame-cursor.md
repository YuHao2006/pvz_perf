# 当前关键帧与帧开始时间：根运动性能实验

候选机制：每个Zombie保存当前关键帧号和帧开始时间；每次计算纳秒年龄，跨帧时推进一次，只有完成整周期才累加基础坐标。固定舍弃每帧不足一纳秒的时长，保留每次更新越过边界的整数余量。普通正向行走、每次最多跨一帧的约束下，避免从完整相位反复除法定位帧。

本页保存独立候选实验的固定负载和数值。随后正式实现已采用[共享reanim帧缓存](../runtime.md)，当前存档定为[v4](../DAT-DAT64-CONVERSION.md)；实验中的每Zombie追加40字节布局不代表最终布局。当前实际RootMotion已经包含固定轨道索引与周期内相位优化。测试复用实际Release对象、真实定义，两个独立进程串行，LP14，每核五轮各200万次，min-of-5，单位ns/更新；11x沿用用户控制条件。

## 所有Zombie的内存代价

Windows x64实测sizeof(Zombie)=608字节。模拟在末尾追加字段：帧开始时间8字节、帧时长8字节、帧号4字节，加对齐后24字节，得到632字节；实验中再存帧时长倒数和坐标系数两个double，共40字节，得到648字节；其中倒数缓存已否决，不能据此推断正式布局。现有mRootOriginX作为基础位置复用。所有僵尸共享布局，冰车、气球等不使用字段也占内存。1024槽池分别增加24KiB／40KiB。ARM64未在本轮编译测量。

100/120/200/240/1000Hz与不规则步长，在60个整秒检查点逐位一致；两个进程精度CSV相同。每周期截位会造成相对当前数学周期的微小时间偏差，但不会因更新频率不同而每次丢弃不同时间。基础坐标每周期一次相加，仍有浮点舍入，不能写成彻底无舍入。

本次实验只测四种正向行走循环，不覆盖正式接入后的变速、动作切换、暂停、读档和事件。实验期间没有改动v3.6存档；其后版本已统一定为v4，未采用当时讨论的v3.7名称。正式数据以当前性能文档的复测为准。
