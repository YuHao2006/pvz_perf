# v4.1.5 高清版 1200p

普僵外观渲染表从 1,134 行缩至 7 行，存档继续使用原有组合编号。铁桶和铁门可分别显示不同破损档位，两者任一尚在时普僵保留手臂。僵王的 1,296 个存档状态共用 3 行渲染数据。

修复了豌豆射手等植物在动作中途的头茎断缝，保留了卷心菜和玉米投手的分段柄。防具各破损档共用裁框和原点，矿工帽保留灯光并清除了延伸到图边的细线。

主菜单 Options、Help、Quit 采用原版字样，经两次离线 Anime4K 放大并修复细节。卡片与战场使用双线性采样。

## Windows 验证

目标为 Windows 10 x64、Vulkan 1.3。完整安装包附带独立测试档。

在关卡中观察射手待机和开火、投手挥柄，以及防具破损时的位置。退出并继续关卡，检查僵尸外观是否还原。
