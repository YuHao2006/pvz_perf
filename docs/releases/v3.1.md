# v3.1

本次提供三个完整运行包：

- `x64-win10-vulkan1.3-v3.1.zip`：Windows 10/11 x64，Vulkan 1.3，需支持 descriptor indexing。
- `x64-win7-openGL3.3-v3.1.zip`：Windows 7 及以上 x64，OpenGL 3.3，需厂商显卡驱动与双源混合。
- `arm64-android14-vulkan1.3-v3.1.apk`：Android arm64，Armv9-A，不要求 SVE，Vulkan 1.3；当前目标机型为 Android 14。

Android 包含程序、资源、完美用户进度及原版转换的无尽基准，安装后无需手动拷贝数据包。
同时提供独立的完美存档和无尽基准压缩包。基准是统一起点，不是个人测试结束后的进度。

## 行为与界面

无尽轮末等待继续推进关卡时间；下一轮选卡镜头开始滑动时才冻结 Board 时间。
选卡预览与界面效果继续推进，保留在场内的对象保持战斗时钟，恢复战斗时继续原进度。
覆盖轮末等待、镜头移动前、选卡和恢复的运行时回归。

已知行为差异：以上为 v3.1 发行包行为。后续核对 1073 发行 EXE 确认，原版在进入
选卡过场时即冻结，早于镜头滑动；当前开发代码已按原版修正，尚未替换此发行包。

修复图鉴及礼盒盆栽的无关卡场景访问、credits 动画与暂停恢复、花园蜗牛和智慧树时序，
修正宽屏大波提示、credits 的原版画面边界与按钮位置。
恢复需要局部裁剪的界面效果；滑入曲线按实际步长更新。
成就滚动和宝石迷阵换位移除旧整周期移动门控。

## 时钟与 Android

对象由所属管理组件传入时间，避免在对象内部假定 Board 存在或自行选择时钟。
移除重复更新的传送门粒子路径；存档序列化继续保存动画实际处理时刻。

目标帧率不得低于 100，读取较小值会修正并回写。
`autoDetectFrameRate` 默认 true，启动时跟随显示器刷新率；明确设置 false 时使用 `targetFps`。
Android 返回键映射 Esc，支持横向翻转以及小窗尺寸变化后的触控映射。
修复小窗系统标题栏、导航栏覆盖和游戏输入区域之间的关系。

Android 用户文件默认位于 `Android/media/com.openpvz.perf/`，旧目录已有资料首次启动时迁移，
不会覆盖新目录中的同名资料。实例锁保存在应用内部，避免共享存储不支持 flock 导致启动失败。
输入时显示可见文本框，支持物理键盘检测；仅接受可打印 ASCII，输入或粘贴其他字符会拒绝。
取消用户名首字母自动大写。

## 存档与资源

游戏仍只直接读写 **DAT64 v4 / schema 0x10745**，本次轮末时序修复不改变磁盘字段布局。
v1.x/v2.x 的存档和旧 PAK64 不能与本版直接混用。
附带转换器支持原版 1073 DAT、DAT64 v1、v2、v4；未发布的 v3 系列中间格式不受支持。
`users.dat` 和 PVZUSR64 v13 用户详情独立于关卡存档。

程序、main.pak64、shader 必须使用同一完整发行包。不要只替换可执行文件。
Windows 包不包含个人设置、个人进度、PDB、构建日志或驱动缓存。
Android 使用项目现有测试签名；若设备上装的是其他签名版本，须自行保存资料后处理签名冲突。

## 性能记录

保留现行性能总账和历史微基准的比较规则；手机与 OpenGL 的阶段性测试不冒充正式优化结论。
这次手机对比观察到的帧率和调度差异不能单独证明 CPU 或 GPU 的具体瓶颈，
Windows Phone 的三角函数预计算调查仅作为后续实验候选，本版未应用该近似。
