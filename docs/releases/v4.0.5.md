# v4.0.5

- 修复 Windows 中文安装目录下的效果文件读取／编译路径：使用 Unicode 文件路径，DXC 的内存源码使用 ASCII 虚拟名称，保留原目录的相对 include 查找。Vulkan 和 D3D12 编译入口均处理；验证覆盖 UTF-8 和 CP936 环境，不要求玩家开启系统 UTF-8 实验选项。
- 修复图鉴入口僵尸缺少脚底阴影的问题。
- 为 Credits 的泳池镜头加入水面闪光，复用现有粒子。闪光随背景移动和裁剪，位于角色和字幕下方；暂停冻结，切换镜头／重播／退出时清理。
- 普通版采用适用的离线烘焙：白天／雾夜水面合入场地背景，战斗、图鉴、Credits 使用一致背景；保留动态焦散。商店车体与后盖合成、裁去多余透明区域，夜间小补片继续复用。
- 外置透明度蒙版合入 PNG，运行时不再自动查找或组合配套透明蒙版。不透明图继续使用 JPG；独立字体字形、遮挡和特效输入图片继续保留。
- 网页版本地文件改由 IndexedDB 持久保存，首次启动迁移旧 IDBFS 数据。用户删除／改名和对应关卡文件的删除均持久化；减少保存时整目录复制。浏览器存储仍受清理策略影响，请保留备份。
- Toy 用户进度和阵型库迁往共享存储，旧私有云档校验后自动迁移；按内容修改时间自动协调本地与云端，覆盖前保留备份。移除手动上传／恢复云端按钮；上传时显示红字，黄字提醒正常 Quit 并等待上传结束。
- 修复旧浏览器缺少 `Object.hasOwn` 导致自动保存报错的问题，兼容函数在模块初始化时选择，不增加每帧判断。
- 网页 PAK 校验后只保留一份可复用的 Wasm 包数据，释放 MEMFS 源副本；支持内存增长和正常 Quit 后重进。
- 网页包保留 wasm64＋WebGPU、wasm64＋WebGL2、wasm32＋WebGL2 三组合，取消 wasm32＋WebGPU。两个 64 位组合启用 SIMD128，32 位 WebGL2 保留标量兼容。浏览器能力检测后选择实际存在的运行时。
- 预留“高清版”入口；默认隐藏，只有配置链接且浏览器支持 Memory64、WebGPU、SIMD128 时显示。本次未设置跳转链接，不发布高清素材包。

**存档格式保持 DAT64 v5.1／schema `0x10747`，用户资料格式不变。** 现有存档无需转换。完整关卡 DAT64 仍不上传云端，需在“高级”中的存档维护功能导出备份；自动云同步覆盖的是用户进度和阵型库。

Windows／Android 共四个原生发行包、两种网页包及完美／无尽存档成套提供。程序、资源、shader 和 DFU 请整套更新。网页版由作者另行上传平台，GitHub 附件发布不代表 Toy 已更新。

验证：main Vulkan／OpenGL 的透明度、图鉴、对话框、商店和 Credits 图像／时钟检查通过，用户已完成桌面手测；三个网页版运行时已在桌面浏览器实际进入游戏。没有新增 Android／Windows 7／手机浏览器实机验收，也没有新增整局 FPS 对照，不承诺某一固定提速幅度。
