# 外部缩放效果

本目录供发行版携带 MagpieFX 格式的缩放效果，不属于 pvz_perf 自有资源。
需要其他效果时，请到 Magpie 项目查找，并保留所取文件的来源和许可说明：

https://github.com/Blinue/Magpie

将效果的 HLSL、所需 include 和配套纹理放入本目录，
在游戏目录的 `scale.json` 中配置窗口及全屏流水线。
流水线引用的效果在启动阶段编译，运行期间切换只使用已准备的结果。
这与构建期编译的游戏内置 shader 是两套输入。

本目录的外部 HLSL 不进入 `main.pak64`。
离线工具生成的 `.vfx` 是可再生中间产物，不是手工维护的源资产。
当前源码构建仍会读取本目录，清理或替换效果时应同时检查默认 `scale.json`
引用和对应构建依赖。

外部效果的许可遵循各自原始文件及上游说明；项目根目录的 LICENSE
不能代替这些文件的来源和许可记录。
