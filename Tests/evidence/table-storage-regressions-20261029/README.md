# 局部只读表的存储期诊断

旧植物状态夹具的FB有三张非static局部constexpr表；仅把它们改成static，其他输入、业务桩、计时和校验保持一致。LP14，MSVC14.51 /O2 /GL-，串行ABBA，原始输出与源码见本目录。2M次总耗时不是完整游戏Update耗时。

射手旧表每次构造424字节，栈帧472→32字节，B总耗时100.05–100.22→49.38–50.33ms；A分支43.24–45.84ms。生产状态1060字节表的栈帧1104→32，B395.93–396.71→88.11–92.03ms，A80.78–91.64ms。各进程内A/B校验一致。

当前Plant.cpp早已static constexpr，不把这项夹具修正称作新增生产提速。旧夹具仍使用整数倒计数，没有出生时间减法；射手剩余约2.5–3ns/次差距与函数指针分派/合成输入有关，不能归因于当前时钟。输入强制所有53种植物经过各状态，不能外推真实射手分布。
