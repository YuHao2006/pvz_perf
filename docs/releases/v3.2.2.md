# v3.2.2

本次为源码检查点，只发布源码、Git提交和版本标签，不上传EXE、APK、PAK64或存档附件。

游戏运行路径恢复到v3.2.1，保留以下两项改动：

- 恢复原版首次入场的水面行为：水面焦散和闪光在新关卡开场由Visual时间驱动；正式开战前平移出生时间，交给Board时间，保留相位、粒子年龄和位置。普通暂停、无尽下一轮选卡停止推进；读档直接使用Board时间。寒冰菇冻结保持不变。
- Vulkan保留两套主绘制资源。第三拍复用第一套前查询对应fence，未完成或没有可用交换链图像时跳过整次屏幕绘制；逻辑、时间和碰撞继续更新，不覆盖仍在GPU使用的数据。延期保持dirty标志，也不增加绘制计数，防止后续文字或FPS叠加层补出半幅画面。

撤回水面工作线程、1536槽粒子分区和异步焦散双纹理试验。游戏仍使用原来的单套粒子池与主线程更新路径。外部双核采集和线程通信微基准保留在Tests/performance，不接入游戏运行，不将未确认的试验结果记作性能提升。

存档沿用v3.2.1的DAT64 v4.0（major4/minor0/schema 0x10745），未增加持久化字段。水面时钟归属标志仅存在于运行期。v1.x/v2.x程序、资源包及存档的破坏性边界不变；未发布的实验v4.1格式不属于本次发行格式。

验证包括Windows Vulkan Release构建、实际水面首次入场／暂停／开战交接／寒冰菇／无尽复选卡回归、完整图像运行期测试、双帧fence非阻塞准入测试和当前v4.0存档加载／写出／重新加载。Android版本标识同步为3.2.2；本次发布不附带APK，手机测试包和实机性能采集另行进行，不据此宣称Android性能收益。
