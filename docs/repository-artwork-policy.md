# Repository artwork policy

PvZ image artwork is not distributed through any Git branch or tag. Original,
Replanted, AI-restored, source/master, runtime, review and screenshot images stay
on the developer machine. Image directories are represented by `.gitkeep`.

Keep resource compiler layout/packing caches (including `assets/definitions/atlas-cache`),
resource definitions, manifests, and generated C++/headers in Git. These are not
removed by the artwork filter. Raster/vector image outputs remain local, even
when generated by a resource compiler. PAKs and pixel-bearing caches are not
made public merely by calling them caches.

A fresh clone needs separately supplied local artwork before rebuilding game
resources. Do not replace the local artwork library with placeholder images.
Do not force-add artwork or merge pre-cleanup history back into public branches.
